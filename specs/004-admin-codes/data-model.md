# Data Model: 공통코드 (admin-codes)

새 테이블과 컬럼은 없다. 키트 `code_groups`, `codes`(`V1_4__codes.sql`)가 기준이다.

## 스펙의 개념과 키트의 대응

| 스펙 | 키트 | 비고 |
|---|---|---|
| 코드 그룹 | `code_groups` (그룹 코드, 이름, 설명) | 지금 moa가 쓰는 그룹은 없다 (spec.md FR-001 표) |
| 코드 | `codes` (그룹, 코드, 이름, 순서, 사용 여부) | 소프트 삭제 |

## 처음 구성

코드 그룹이 없다. 그룹을 쓰는 기능이 생기면 그 기능의 스펙이 그룹과 초기 코드를 정하고, spec.md FR-001 표에 한 줄 더한다 (FR-002).

## 검증 규칙 (키트)

- 그룹 코드·코드: 영문 대문자·숫자·밑줄. 만든 뒤 바꾸지 않는다. 그룹 코드는 50자 이하
- 그룹 이름: 필수, 100자 이하. 그룹 설명: 500자 이하
- 그룹 코드와 그룹 안의 코드는 겹치면 안 된다
