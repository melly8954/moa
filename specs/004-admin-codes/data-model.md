# Data Model: 공통코드 (admin-codes)

새 테이블과 컬럼은 없다. 키트 `codes`(`V1_4__codes.sql`)가 기준이다.
키트 `code_groups`는 moa에서 지웠다(`V2_7__code_groups_from_code.sql`). 그룹은 코드에 등록한다 (spec.md FR-004, research.md R5).

## 스펙의 개념과 키트의 대응

| 스펙 | 키트 | 비고 |
|---|---|---|
| 코드 그룹 | 코드 등록 `CodeGroupSource` → `CodeGroupRegistry` (그룹 코드, 이름, 설명, 쓰는 곳) | 지금 moa가 쓰는 그룹은 없다 (spec.md FR-001 표) |
| 코드 | `codes` (그룹, 코드, 이름, 순서, 사용 여부) | 소프트 삭제. 코드를 비우면 자동 순번 (FR-006) |

## 처음 구성

코드 그룹이 없다. 그룹을 쓰는 기능이 생기면 그 기능의 스펙이 그룹과 초기 코드를 정하고, 코드에 그룹을 등록하고, spec.md FR-001 표에 한 줄 더한다 (FR-002).
local 프로필만 시험 그룹 둘(`LocalCodeGroups`)을 등록한다 (quickstart "화면 확인").

## 검증 규칙 (키트)

- 그룹 코드·코드: 영문 대문자·숫자·밑줄. 만든 뒤 바꾸지 않는다. 그룹 코드는 50자 이하
- 그룹(코드 등록): 그룹 코드 `[A-Z][A-Z0-9_]{0,49}`, 이름·쓰는 곳 필수, 겹치면 시작이 실패한다
- 그룹 안의 코드는 겹치면 안 된다
