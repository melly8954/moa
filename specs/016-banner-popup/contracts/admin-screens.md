# Contract: 배너·팝업 관리 화면

관리 셸 안의 화면이다. 목록 + 드로어 + 체크박스 일괄 처리 틀을 따른다 (`001-admin-menus` "관리 화면 정리", research R9).

## 배너 관리 (`/admin/banners`)

- 머리: 제목 "배너 관리", 설명 "홍보 배너 이미지와 노출 기간, 순서를 정해요. 아직 사용자 화면에는 보이지 않아요. 짧은 글 안내는 공지 관리에서 해요." ("공지 관리"는 `/admin/notices` 링크). 오른쪽에 "배너 등록" 단추
- 검색: 상태(끝남 빼고(기본), 예정, 노출 중, 끝남, 꺼짐, 전체), 이름. 값은 주소에 둔다 (`useListSearch`)
- 일괄 처리 줄: 표 위 늘 같은 자리·높이. 고른 것이 없으면 "고르면 한꺼번에 처리할 수 있어요" 같은 안내와 꺼진 단추, 고르면 "N개 선택"과 켜기·끄기·삭제 단추. 삭제만 확인 창을 띄운다
- 표 열: 체크 칸, 이미지(작은 넓은 화면 이미지), 이름, 기간(시작 ~ 끝, 끝이 없으면 시작 ~), 순서, 상태(노출 중은 긍정, 꺼짐·끝남은 흐림)
- 행을 누르면 드로어가 열린다. 체크 칸을 누를 때는 열지 않는다
- 쪽이나 검색이 바뀌면, 일괄 처리가 끝나면 고른 것이 풀린다

### 배너 드로어

| 칸 | 입력 |
|---|---|
| 이름 | 글자 (1~100자) |
| 넓은 화면 이미지 | 파일 고르기(JPG·PNG·WebP, 5MB까지, 권장 1200×300). 올린 뒤 바꾸기·지우기 |
| 좁은 화면 이미지 | 같은 방식(권장 720×360). 선택 |
| 미리보기 | 넓은 화면 틀(4:1)과 좁은 화면 틀(2:1)을 나란히. 좁은 화면용이 없으면 넓은 화면용을 보이고 "좁은 화면 이미지가 없어 넓은 화면 이미지를 써요" 안내 (US1-AC10) |
| 대체 문구 | 글자 (1~200자) |
| 연결 주소 | 글자. `/`로 시작하는 내부 주소나 `http`·`https` 주소 |
| 노출 기간 | 시작 날짜·시각(필수), 끝 날짜·시각(선택) |
| 순서 | 숫자, 기본 0 |
| 켜짐 | 스위치, 기본 켜짐 |

- 아래 줄: 고칠 때는 삭제(확인 창)와 저장, 등록할 때는 취소와 등록
- 저장 실패의 칸 오류는 그 칸 아래에 보인다 (US1-AC7)
- 바꾼 채 닫으면 닫을지 묻는다

## 팝업 관리 (`/admin/popups`)

- 머리: 제목 "팝업 관리", 설명 "사용자 화면에 들어올 때 뜰 팝업과 노출 기간, 순서를 정해요. 아직 사용자 화면에는 보이지 않아요." 오른쪽에 "팝업 등록" 단추
- 검색: 상태(배너와 같다), 제목
- 일괄 처리 줄과 표 동작은 배너와 같다. 표 열: 체크 칸, 제목, 기간, 순서, 상태

### 팝업 드로어 (넓은 드로어)

| 칸 | 입력 |
|---|---|
| 제목 | 글자 (1~200자) |
| 내용 | 서식 있는 글 편집기 (공지와 같다, 이미지 넣기 가능) |
| 연결 주소, 노출 기간, 순서, 켜짐 | 배너와 같다 |

## 메뉴

- 관리 셸 사이드바: 운영, 마케팅(배너 관리, 팝업 관리), 설정 순서 (`001-admin-menus` FR-001)
- 권한이 없는 운영자에게는 메뉴가 흐리게 보이고 자물쇠가 붙는다 (`001-admin-menus` FR-002)

## 화면 문구

`messages/ko.json`의 `banner`, `popup` 묶음에 둔다. 두 화면이 같이 쓰는 상태 이름, 상태 거르기, 노출 기간·연결 주소·순서·켜짐 칸은 `marketing` 묶음이다. 일괄 처리 문구는 다른 관리 화면과 같은 이름(`bulkToolbar`, `bulkHint`, `bulkSelected`, `bulkEnabled`, `bulkDisabled`, `bulkRemoved`, `bulkRemoveTitle`, `bulkRemoveDescription`)을 쓴다. 상태 이름은 `marketing`의 `statuses.<값>`이다.
