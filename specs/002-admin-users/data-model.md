# Data Model: 관리자·운영자 계정 (admin-users)

새 테이블과 컬럼은 없다. 키트 `users` 테이블과 `User` 엔터티가 기준이다.

## 스펙의 개념과 키트의 대응

| 스펙 | 시스템 역할 (`role`) | 권한 | 만드는 곳 |
|---|---|---|---|
| 관리자 | `ADMIN` | 모든 권한 | 첫 관리자는 부트스트랩, 이후 사용자 관리에서 역할을 바꾼다 |
| 운영자 | `USER` | 받은 업무 역할의 권한 (`003-admin-roles`) | 사용자 관리에서 만든다 |

운영자와 일반 회원은 시스템 역할이 같다 ([research.md](./research.md) R2).

## 임시 비밀번호 상태

`password_change_required`가 상태를 나타낸다.

```text
만들기(부트스트랩·사용자 관리) → true → 내 비밀번호 바꾸기 → false
```

## 검증 규칙 (키트)

- 아이디: 영문·숫자·`.`·`_`·`-` 3~50자, 겹치면 안 된다
- 이름: 필수, 50자 이하
- 첫 관리자 비밀번호: 8자 이상
