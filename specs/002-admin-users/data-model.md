# Data Model: 관리자·운영자 계정 (admin-users)

새 테이블과 컬럼은 없다. 키트 `tb_user` 테이블과 `User` 엔터티가 기준이다.

## 스펙의 개념과 키트의 대응

| 스펙 | 시스템 역할 (`role`) | 권한 | 만드는 곳 |
|---|---|---|---|
| 최고 관리자 | `ADMIN` | 모든 권한 (최고 관리자 역할, `003-admin-roles` FR-010) | 첫 관리자는 부트스트랩, 이후 최고 관리자가 다른 관리자 계정을 최고 관리자 역할에 넣는다 |
| 운영자 | `ADMIN` | 받은 역할의 권한 (`003-admin-roles`) | 사용자 관리에서 계정 종류 "관리자"로 만든다 |
| 회원 | `USER` | 관리 권한 없음, 역할을 받지 않는다 | 가입(사용자 쪽 기능) 또는 사용자 관리 |

2026-11-21에 바꿨다. 그 전에는 관리자가 `ADMIN`(모든 권한), 운영자가 `USER` + 업무 역할이라 운영자와 회원의 시스템 역할이 같았다 ([research.md](./research.md) R2, R9). 화면에서는 시스템 역할을 "계정 종류"(회원·관리자)로 부른다.

## 임시 비밀번호 상태

`password_change_required`가 상태를 나타낸다.

```text
만들기(부트스트랩·사용자 관리) → true → 내 비밀번호 바꾸기 → false
```

## 검증 규칙 (키트)

- 아이디: 영문·숫자·`.`·`_`·`-` 3~50자, 겹치면 안 된다
- 이름: 필수, 50자 이하
- 첫 관리자 비밀번호: 8자 이상
