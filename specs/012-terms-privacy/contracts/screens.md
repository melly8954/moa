# Contract: 이용약관·개인정보처리방침 화면과 링크

서버 API는 없다. 화면은 요청마다 서버에서 그린다 (research R5).

## 문서 화면 (`(legal)` 경로 묶음, research R4)

| 경로 | 보이는 것 |
|---|---|
| `/terms`, `/privacy` | 지금 시행 중인 버전. 예정 버전이 있으면 위에 안내 띠 |
| `/terms/versions/{version}`, `/privacy/versions/{version}` | 그 버전. 지금 버전이 아니면 위에 안내 띠 |

누구나 연다. 로그인 확인을 하지 않는다. 관리자 계정도 막지 않는다 (FR-001).

### 화면 구성

1. 머리 줄 (FR-011, US1-AC6): 왼쪽 "moa"(`/`로 가는 링크), 오른쪽 "이용약관"·"개인정보처리방침" 링크(지금 문서는 `aria-current`). 인쇄 때 숨긴다
2. 안내 띠 (US3, 인쇄 때 숨김)
   - 지금 버전 화면 + 예정 버전 있음: "YYYY년 M월 D일부터 바뀝니다" + "바뀌는 내용 미리 보기"(예정 버전 화면 링크)
   - 예전 버전 화면: "지금 시행 중인 버전이 아니에요" + "지금 버전 보기"
   - 예정 버전 화면: "YYYY년 M월 D일부터 시행돼요. 아직 시행 전이에요" + "지금 버전 보기"
3. 제목(`h1`), 버전·시행일 줄("시행일 YYYY-MM-DD · 버전 {version}"), "다른 버전 보기"(버전 목록을 펼친다)
4. 버전 목록 (US3-AC1): 시행일 최근순. 예정 버전은 "예정", 지금 버전은 "지금 시행 중" 표시. 각 줄은 그 버전 화면 링크
5. 목차 (US1-AC5): 장 제목 링크(`#id`)
6. 장마다 `<section id>` + `h2` + 본문. 표는 표 안에서만 가로 스크롤 (US1-AC4)

### 없는 버전

`/…/versions/{없는 버전}`: "없는 버전이에요" 안내와 "지금 버전 보기" 링크. 응답 코드는 404

## 링크 (FR-004, FR-005, US2)

| 자리 | 모양 | 여는 방식 |
|---|---|---|
| 로그인 화면 `/sign-in`, `/sign-in/recover` 맨 아래 | "이용약관 · **개인정보처리방침**" 작은 글자 한 줄 | 같은 탭 |
| 가입 화면 `/sign-up/nickname` 맨 아래, 약관 칸 옆 | 같은 줄. 약관 칸 옆에는 "새 탭에서 보기" 링크(이용약관 칸은 /terms, 개인정보 수집·이용 칸은 /privacy) | 새 탭 (US2-AC4) |
| 사용자 셸 사이드바 계정 줄 밑 (펼침·서랍) | 같은 줄 | 같은 탭 |
| 사용자 셸 사이드바 접힘 | 정보 아이콘 단추("약관과 정책") → 두 링크가 든 메뉴 | 같은 탭 |
| 관리 셸 | 없다 (US2-AC5) | |

- 010 가입 화면의 약관 칸은 지금처럼 요약과 "전문 보기"(펼치기)를 두고, 펼친 전문은 문서 보기 부품의 작은 모양으로 그린다 (research R2·R3)

## 화면 문구

`messages/ko.json`의 `legal` 묶음: 문서 이름, 머리 줄, 안내 띠, 버전 목록, 목차, 없는 버전, 링크 줄, 정보 아이콘 이름. 문안 자체는 문구 파일에 넣지 않는다 (spec 배경).
