# Contract: 알림 화면

API는 [notifications-api.md](./notifications-api.md), 실시간은 [realtime.md](./realtime.md).

## 벨 (로그인 뒤 셸)

| 자리 | 모양 |
|---|---|
| 사이드바 계정 줄 | 벨 아이콘 + 안 읽은 수(없으면 숫자 없음, 99 넘으면 "99+"). 접으면 아이콘 위 숫자 점 |
| 좁은 폭 화면 머리 | 서랍 단추 옆에 같은 벨 (사이드바가 서랍일 때) |

- 누르면 팝오버: 최근 10개(제목, 시각, 안 읽음 표시), "모두 읽음", "모두 보기"(→ `/notifications`). 비었으면 빈 결과 안내
- 알림을 누르면 읽음 처리 뒤 `link`로 간다
- 화면 낭독기: "알림, 안 읽은 알림 3개"

## 알림 화면 `/notifications` (로그인, `(main)`)

- 머리: "알림", "모두 읽음" 단추
- 브라우저 알림: 켜기·끄기 스위치
  - 지원 안 함: "이 브라우저는 브라우저 알림을 지원하지 않아요"
  - 권한 거부: 꺼짐 + "브라우저 설정에서 알림을 허용해 주세요"
  - 서버 웹 푸시 꺼짐(공개 키 없음): 스위치 대신 "지금은 브라우저 알림을 쓸 수 없어요"
- 목록: 내 알림 최신순(제목, 시각, 안 읽음 표시), 페이지. 누르면 읽음 뒤 `link`

## 토스트 (화면을 보고 있을 때)

| 메시지 | 토스트 | 함께 바뀌는 것 |
|---|---|---|
| 공지 게시 | "새 공지: {제목}" | "공지" 메뉴 새 공지 점 (`006-notices`) |
| 개인 알림 | "{제목}" | 벨 숫자 +1, 펼침 목록 다시 읽기 |

- 토스트의 "보기" 단추를 누르면 `link`로 간다 (개인 알림은 읽음 처리 뒤). 단추라 키보드로도 누를 수 있다
- 다시 연결되면 벨 숫자와 새 공지 여부를 다시 읽는다
