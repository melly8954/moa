# Contract: 화면 (018)

근거는 [research.md](../research.md) R10. 문구는 `messages/ko.json`에 두고 구현 때 확정한다.

| 주소 | 셸 | 내용 |
|---|---|---|
| `/account/profile` (기존) | account | 머리 "마이페이지" 아래 탭 "프로필"(지금)·"계정 관리". 내용은 009 그대로 (US1-AC1) |
| `/account/profile/manage` (새) | account | 같은 머리와 탭. 더해진 항목이 순서대로, 맨 아래 오른쪽에 빨간 "탈퇴하기". 항목이 없으면 그 영역만 (US1-AC1, US4-AC1·AC2). 관리자 계정이면 009와 같은 권한 없음 안내 |
| `/sign-in/recover` (새) | public | 탈퇴한 계정이라는 안내, 완전 삭제 예정 시각, "복구하기", "취소". 복구 쿠키가 없으면(A403) 로그인 화면으로 (US2-AC1·AC5) |
| `/sign-in` (기존) | public | `?withdrawnUntil=<시각>`이면 "탈퇴했어요. {시각}까지 다시 로그인하면 복구할 수 있어요." (US1-AC5). `oauthError=purgePending`과 A402 문구 |
| `/admin/purge-logs` (기존) | admin | 종류 "회원" |

- 탭은 링크다. 저장하지 않은 프로필이 있으면 떠나기 전에 묻는다 (Edge Case)
- 메뉴로 열지 않는 계정 화면이라 프로그램으로 등록하지 않는다 (`001-admin-menus` FR-008)

## 탈퇴 확인 창

- 안내 세 가지: 30일 복구, 그 뒤 완전 삭제, 글·댓글·파티·메시지는 "탈퇴한 회원"으로 남음 (US1-AC2, FR-003)
- 입력 "닉네임"과 지금 닉네임 안내. 앞뒤 공백을 뺀 값이 같아야 빨간 "탈퇴하기"가 켜진다 (US1-AC3)
- 취소·닫기: 탈퇴하지 않고 입력을 비운다 (US1-AC9)
- 서버 오류: V001은 칸 아래 "닉네임이 달라요.", 그 밖은 공통 문구
- 성공: 브라우저 알림을 끄고 로그아웃한 뒤 `/sign-in?withdrawnUntil=…`

## 로그인 화면에서

- 로그인이 A401이면 `/sign-in/recover`로 (`next`가 있으면 붙임)
- 복구하면 로그인한 때와 같이 `next` 또는 첫 화면으로
- 취소하면 `/sign-in`으로. 탈퇴 상태는 그대로다 (US2-AC5)
