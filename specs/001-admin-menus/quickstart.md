# Quickstart: 관리 메뉴와 접근 (admin-menus)

기대 결과의 기준은 [contracts/admin-access.md](./contracts/admin-access.md)와 [data-model.md](./data-model.md)다.

## 자동 검증

Docker가 떠 있어야 한다. `backend/`에서 실행한다 (Windows는 `.\gradlew.bat`).

```bash
./gradlew dbTest --tests "*AdminMenusAcceptanceTest"
```

기대: `US1-AC1`~`US5-AC5`가 통과한다.

셸 나누기(US1-AC1의 첫 화면·사이드바, US2-AC1, US2-AC4), 사이드바 묶음 펴기·접기(US1-AC4~AC8), 메뉴 관리 화면(US5)은 `frontend/`의 e2e로 본다: `npx playwright test e2e/menu.spec.ts e2e/auth.spec.ts`. 로컬에서는 돌리지 않고 PR CI로 본다

## 화면 확인

자동 테스트가 보지 못하는 모양(화살표, 선, 끌기 느낌)과 안내 문구는 아래로 직접 본다.

1. `backend/`에서 `./gradlew bootRun`, `frontend/`에서 `npm run dev`
2. 시험 계정 `admin`으로 로그인: 사용자 관리 화면이 열리고, 사이드바에 홈 없이 "운영"·"설정" 묶음이 이 순서로 보인다. 각 화면에 목록이 나온다. 계정 메뉴의 설정·비밀번호 변경·알림 화면도 관리 셸 안에서 열린다. 본문 위에 머리 줄이 없고, 로고 옆 단추로 사이드바를 접으면 아이콘만 남으며 로고 자리 단추로 다시 펼쳐진다. 창을 좁히면 머리 줄에 서랍 단추, moa, 벨이 보인다
   - 사이드바의 로고 줄 아래와 계정 줄 위에 선이 있고, 하위 메뉴는 묶음 아래 왼쪽 선을 따라 들여 보인다
   - 지금 화면이 있는 "운영"만 펴져 있고(사용자 관리, 공지 관리, 접속 이력), "설정"은 접혀 있다. 묶음 오른쪽 화살표는 펴지면 아래를 향한다
   - "설정"을 눌러 펴고 새로 고친다: 펴진 채다. 다시 눌러 접고 새로 고친다: 접힌 채다
   - "설정"을 펴고 공통코드로 간다: "운영"도 펴진 채다. 지금 화면이 있는 "설정"을 접고 새로 고쳐도 접힌 채다
   - 사이드바를 아이콘만 남게 접고 "설정" 아이콘을 누른다: 사이드바가 펼쳐지고 "설정"이 펴진다
3. 시험 계정 `admin`으로 메뉴 관리를 연다: 머리 설명에 "사이드바에 보일 메뉴와 묶음, 순서를 정해요. 누가 어떤 관리 메뉴를 쓰는지는 역할 관리에서 정해요."가 보이고 "역할 관리"는 링크다. "프로그램" 탭은 없다
   - "관리자 메뉴" 탭: 묶음 아래 하위 메뉴가 들여 쓰인 트리 표가 쪽 나눔 없이 보이고, 행마다 체크박스·끌기 손잡이·이름·보이는 사람·사용만 있고 단추는 없다
   - "접속 이력"을 손잡이로 끌어 "설정" 묶음 안에 놓는다: 사이드바의 "설정" 아래로 옮겨진다. 키보드(손잡이에서 스페이스, 화살표, 스페이스)로 되돌린다
   - 메뉴 이름을 누른다: 오른쪽 드로어에 이름·아이콘·종류·프로그램·사용이 열린다. 이름을 고치고 저장 없이 닫으려 하면 닫을지 묻는다. 창을 좁히면 드로어가 화면 전체를 덮는다
   - 메뉴 둘을 체크하고 "사용 안 함"을 누른다: 둘 다 사이드바에서 빠진다. 다시 "사용"으로 되돌린다. 하위 메뉴가 있는 묶음과 다른 메뉴를 함께 체크해 "삭제"를 누르면 아무것도 지워지지 않고 이유가 보인다
   - "메뉴 추가"로 묶음 메뉴 "시스템"을 만들고 그 아래에 프로그램 "공통코드" 메뉴를 더한다: 프로그램 선택 상자에 이름과 경로·필요한 권한 이름이 보이고, 경로나 권한을 입력하는 칸은 없다. 사이드바에 "시스템" 아래 공통코드가 보인다. 지운 뒤 다음으로
   - "사용자 메뉴" 탭에서 메뉴를 하나 더한다(예: 이름 "시험", 프로그램 "공지", 공개 범위 "비회원 포함"): 로그아웃한 공지 화면과 `user` 사이드바에 보이고, 공개 범위를 "회원만"으로 바꾸면 로그아웃한 화면에서 빠지고, 끄면 모두에서 빠진다. 지운 뒤 다음으로
4. 시험 계정 `user`로 로그인: 사용자 셸 첫 화면이 열리고 사이드바에 홈, 공지만 있다. `/admin/users`로 직접 들어가면 목록 자리에 "이 화면을 볼 권한이 없어요."가 보인다
5. 로그아웃 뒤 `/admin/users`로 들어가면 로그인 화면으로 간다. 로그인하면 그 주소로 돌아온다
