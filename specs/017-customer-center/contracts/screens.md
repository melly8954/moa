# 화면: 고객센터 (customer-center)

문구는 `messages/ko.json`의 `faq`, `inquiry`, `support` 아래에 둔다. 결정의 이유는 [research.md](../research.md) R11·R12를 본다.

## 관리 셸

### FAQ 관리 `/admin/faqs` (구성 목록)

- 머리: 제목 "FAQ 관리", 설명은 spec FR-016 (문의 관리 링크)
- 검색: 분류(전체 + 항목), 켜짐(전체·켜짐·꺼짐), 검색어(질문)
- 일괄 처리 줄: 켜기, 끄기, 삭제(확인). 표 위 같은 자리 (`001-admin-menus` FR-010)
- 표: 체크, 분류, 질문, 순서, 켜짐. 쪽 없이 표 안에서 스크롤. 머리 오른쪽에 "FAQ 등록"
- 드로어(넓게): 분류 선택, 질문, 답(`RichTextEditor`), 순서(기본 0), 켜짐(기본 켜짐), 저장·삭제. 저장하지 않고 닫으면 묻는다
- 200개면 등록 단추를 누를 때 상한 안내 (`B301`)

### 문의 관리 `/admin/inquiries` (업무 목록)

- 머리: 제목 "문의 관리", 설명은 spec FR-016 (FAQ 관리 링크)
- 검색: 상태(답변 대기(기본)·답변 완료·전체), 분류, 기간 빠른 단추, 검색어(제목·작성자)
- 표: 상태, 분류, 제목, 작성자(이름·아이디), 쓴 시각, 답변 시각. 쪽 이동 (`011-list-screen`)
- 드로어(넓게): 분류·제목·작성자·쓴 시각, 내용(줄바꿈 그대로), 첨부 작은 그림(누르면 크게), 답변(`RichTextEditor`)과 저장. 답변 완료면 답변 시각과 답변한 관리자, 저장은 "답변 고치기"
- 작성자가 탈퇴했으면 답변 칸 대신 "탈퇴한 회원의 문의라 답변할 수 없어요." (US5)

## 사용자 셸

### 고객센터 FAQ `/support` (로그인 없이)

- 머리: 제목 "고객센터", 오른쪽에 "1:1 문의하기", 로그인했으면 "내 문의"
- 분류 단추 줄: 전체 + 사용 중인 분류. 검색어 칸. 둘 다 주소에 남는다
- 질문 목록: 누르면 그 자리에서 답이 펼쳐지고 다시 누르면 접힌다
- 결과가 없으면 "찾는 답이 없나요?"와 "1:1 문의하기"

### 내 문의 `/support/inquiries` (로그인)

- 표(좁은 폭은 줄 목록): 분류, 제목, 상태 배지, 쓴 날짜. 쪽 이동
- 비었으면 안내와 "1:1 문의하기"

### 문의 쓰기 `/support/inquiries/new` (로그인)

- 분류 선택, 제목(100자), 내용(2000자, 남은 글자 수), 이미지 붙이기(작은 그림과 빼기, 다섯 장이면 붙이기 단추가 꺼지고 "이미지는 다섯 장까지 붙일 수 있어요.")
- 보내면 상세로 간다. 칸 오류는 그 칸 아래에

### 문의 상세 `/support/inquiries/{id}` (로그인)

- 분류, 제목, 상태, 쓴 시각, 내용, 첨부(누르면 크게)
- 답변이 있으면 "moa 운영팀"과 답변 시각, 답변 내용
- 답변 대기면 "지우기"(확인). 없는 문의면 "없는 문의예요."와 내 문의로 가는 단추
