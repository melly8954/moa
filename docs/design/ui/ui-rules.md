# UI 규칙

- 테마와 컴포넌트의 값은 프론트 코드가 정본이다. 여기에는 값을 적지 않는다
- 테마·컴포넌트 경로와 키트 버전: `docs/design/architecture.md` UI 절
- 커스터마이즈는 테마 변수로만 한다. 컴포넌트 코드의 스타일을 직접 바꾸지 않는다
- 여기에는 화면을 그릴 때의 규칙만 둔다. 프론트 코드 규칙은 `docs/design/conventions.md` 프론트 절이 소유한다

## 테마 사용 규칙

- 색은 테마 변수의 Tailwind 클래스(`bg-primary`, `text-muted-foreground`, `text-destructive` 등)만 쓴다. 원색 값(`#fff`, `red-500`)을 쓰지 않는다
- 강조색(primary)은 화면에서 가장 중요한 행동 하나에만 쓴다. 나머지 행동은 outline·ghost·secondary
- 라이트·다크 둘 다 테마 변수로 그려지므로 다크 전용 색을 따로 쓰지 않는다
- 게임은 색이 아니라 이름(Badge outline)으로 구분한다

## 레이아웃 규칙

- 모바일 우선. 기준점은 `md`(768px). 360px 폭에서 가로 스크롤이 없어야 한다 (NFR-ENV-001)
- 본문 폭
  - 피드·프로필·게시물: 가운데 한 줄, `max-w-2xl`
  - 목록·설정·관리: `max-w-5xl`
  - 셸 없는 화면(로그인·가입): 가운데 카드, `max-w-sm`
- 좌우 여백 `px-4`
- 본문 폭은 셸 본문 칸 안의 페이지 상자에 건다. 셸 본문 칸 자체는 폭을 정하지 않는다 〔2026-10-02〕 목업에서 폭이 무시돼 빈 공간이 넓게 보였다
- 간격 단계 〔2026-10-02〕 화면마다 간격 값이 섞여 있어 정했다

  | 쓰는 곳 | 값 |
  |---|---|
  | 페이지 구역 사이 (카드와 카드, 제목과 본문) | `gap-6` |
  | 카드·대화상자 안 구역, 폼 입력칸 사이 | `gap-4` |
  | 읽기 카드(게시물, 모집, 평가) 안 요소 사이 | `gap-3` |
  | 묶음 안: 이름표와 입력, 버튼 묶음, 배지 묶음 | `gap-2` |
  | 텍스트 줄 묶음: 이름과 부가 정보, 말풍선과 시각 | `gap-1` |
  | 목록 한 줄의 위아래 | `py-3`, 아바타와 글 사이 `gap-3`, 줄 사이 구분선 `divide-y` |
  | 사진 격자 | `gap-1` |

  - 컴포넌트 안쪽 여백(Card, Dialog, Button 등)은 컴포넌트가 정한다. 바깥에서 덮어쓰지 않는다
- 대화(SCR-MSG-001·002)는 `md` 이상에서 목록과 방을 나란히, 미만에서 따로 보여 준다
- 표(Table)는 관리 화면에서만 쓴다. 회원 화면의 목록은 카드나 줄 목록으로 그린다 (모바일 폭)
- 회원을 보여 주는 줄은 Avatar + 닉네임 + 부가 정보(레벨, 티어) 순서로 통일한다

## 상태 표시 규칙

- 빈 상태: 점선 테두리 안내 + 다음 행동 Button. 기본은 하나, FR이 안내할 곳을 둘 정하면 둘 (예: FR-REL-004 E1, FR-MSG-004 E1)
- 로딩: Skeleton으로 실제 배치 모양을 흉내 낸다. 300ms 안에 끝나면 보이지 않게 한다
- 오류: Alert destructive + 다시 시도 Button. 입력 오류는 입력칸 아래 `text-destructive` 문구
- 무한 스크롤(피드, 목록): 아래에 이어서 불러오는 Skeleton, 끝이면 "모두 봤습니다" 문구
- 잠깐 알리는 결과(저장, 복사, 신고 접수)는 Sonner. 사용자가 읽어야 하는 실패는 Alert
- 찾을 수 없는 회원·게시물(R001)은 오류가 아니라 빈 상태 모양으로 "찾을 수 없습니다"를 보여 준다

## 문구 규칙

- 화면 문구는 한국어·영어 두 벌을 만든다. 목업은 한국어로만 그린다 (NFR-I18N-001)
- 버튼은 동사로 끝낸다 (저장, 보내기, 팔로우하기 대신 팔로우)
- 존댓말 "~합니다/~하세요"로 쓴다
- 용어는 `docs/glossary.md`를 따른다
- 시각은 KST로 보여 준다. 24시간 안은 "3분 전"처럼 상대 시각, 그 밖은 날짜
- 개인정보(이메일, 생년월일, 휴대폰 번호)는 본인 설정·관리자 화면에만 그린다. 관리자 화면의 휴대폰 번호는 가운데 4자리를 가린다 (SEC-PRIV-002)
  - 예외: 가입 중 휴대폰 번호 중복 안내의 가린 이메일 (SEC-PRIV-002 예외, `member/_policy.md`)
- 관리자가 원문 보기로 연 사용자 화면(게시물, 프로필)에는 회원 행동 버튼(팔로우, 메시지, 좋아요, 댓글, 신고, 참여)을 그리지 않는다. 관리자는 회원 활동을 하지 않는다 (`docs/req/actors.md`, `admin/_policy.md`)
- 비회원에게는 회원 행동 버튼을 그리고, 누르면 로그인 안내로 보낸다
