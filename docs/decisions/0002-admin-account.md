# 관리자 계정은 최초 1명을 시드하고 이후는 화면에서 만든다

- 상태: 확정 (2026-11-07)
- 바꾸는 결정: 예전 기획의 "관리자는 배포 때 한 명만 시드한다"

## 배경

예전 기획은 운영자가 한 명이라 배포 때 관리자 한 명만 만들기로 했다. 비밀번호를 저장소에 두지 않으려고 이메일과 비밀번호 해시는 배포 환경변수로 넣기로 했다.
0001에서 rbac를 넣어 관리자를 여럿 둘 수 있게 되었다.

키트는 local 프로필에서만 시험용 계정(`admin`, `user`)을 만든다. 운영 환경의 첫 관리자를 만드는 방법은 키트에 없다.

## 결정

- 배포 때 최초 ADMIN 1명을 만든다. 아이디와 비밀번호 해시는 저장소가 아니라 배포 환경변수로 넣는다
- 그 뒤 운영자는 관리자가 사용자 관리 화면에서 만들고 역할을 준다
- 관리자 계정은 관리와 조회만 한다. 게시물 작성, 파티, 메시지 같은 회원 활동은 하지 않는다 (예전 정책 유지)

## 결과

- 최초 관리자 시드는 키트에 없어 moa가 만든다. 다른 프로젝트에도 필요하면 키트로 올릴 후보다
- "관리자는 회원 활동을 하지 않는다"를 어떻게 막는지는 회원 기능(사용자 쪽)과 맞춰야 한다
