# 미결 사항

아직 정하지 않은 것(미정)과 정하지 않고 진행하기로 한 것(보류)을 모은다. 기획·설계·구현 어느 단계에서 생긴 것이든 여기에 둔다 (harness-psw 8.2).

- 원천 문서에는 자리표시 `[OPEN-NNN]`만 두고, 내용은 이 파일에 적는다
- 해결되면 원천의 자리표시를 값과 결정 기록(`〔YYYY-MM-DD〕 이유`)으로 바꾸고, 이 파일에서 항목을 지운다
- ID는 `.claude/scripts/psw/next-id.sh OPEN`으로 받는다. 지운 ID는 다시 쓰지 않는다
- 항목 형식은 스크립트가 읽는다. 제목 줄과 `- 상태:` 줄의 모양을 바꾸지 않는다
- 상태는 `미정`, `보류` 둘만 쓴다. 보류는 사용자만 정한다
