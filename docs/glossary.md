# 용어집

- 코드 이름은 이 표의 `코드 이름`을 따른다
- 같은 개념을 다른 말로 부르지 않는다. `쓰지 않는 말`에 적힌 표현은 문서와 코드에서 쓰지 않는다
- 용어를 추가하거나 바꾸면 커밋 본문에 이유를 적는다. 관련 요구사항이 있으면 `Refs` 트레일러를 단다

| 용어 | 코드 이름 | 정의 | 쓰지 않는 말 |
|---|---|---|---|
| 회원 | `Member` | 가입한 사용자. 게이머와 게임 관련 직업인을 같은 역할로 둔다 | 유저, 사용자(역할을 가리킬 때) |
| 비회원 | `Guest` | 로그인하지 않은 방문자 | 손님, 익명 |
| 관리자 | `Admin` (역할 `MemberRole.ADMIN`) | 신고 처리, 제재·해제, 탈퇴 계정 복구, 게임 목록을 관리하는 역할 | 운영자 |
| 회원 상태 | `MemberStatus` | 회원 계정의 상태. ACTIVE·SUSPENDED·WITHDRAWN·PURGED. 값의 정본은 회원 `_policy.md` 상태 전이 절이다 | |
| 로그인 수단 | `LoginMethod` | 계정에 연결된 로그인 방법. PASSWORD·GOOGLE·KAKAO | 인증 수단, 로그인 방식 |
| 제공자 | `OAuthProvider` | 소셜 로그인을 제공하는 외부 서비스. GOOGLE·KAKAO | 플랫폼, 소셜 |
| 연결된 소셜 계정 | `MemberSocialAccount` | 회원 계정에 연결된 제공자 계정 하나 | 연동 계정 |
| 연결 / 해제 | `link` / `unlink` | 로그인 수단을 계정에 붙이거나 떼는 일 | 연동, 바인딩 |
| 계정 이메일 | `email` | 계정마다 하나인 이메일. 비밀번호 로그인과 비밀번호 찾기의 기준이다 | 로그인 아이디 |
| 가입 진행 | `SignUp` | 회원이 생기기 전 가입 단계에서 확인된 값을 담는 임시 기록 | 가입 세션, 임시 회원 |
| 이메일 인증 | `EmailVerification` | 메일로 보낸 링크로 이메일 주인임을 확인하는 일 | 메일 확인 |
| 휴대폰 인증 | `PhoneVerification` | 문자로 보낸 인증 번호로 그 번호를 지금 가진 사람임을 확인하는 일 | 본인인증(CI 인증과 혼동) |
| 인증 번호 | `verificationCode` | 휴대폰 인증에 쓰는 6자리 번호 | OTP |
| 닉네임 | `nickname` | 서비스 안에서 보이는 회원 이름. 대소문자를 구분하지 않고 중복 불가 | 별명, 아이디 |
| 소개 | `bio` | 프로필의 짧은 소개 글 | 자기소개 |
| 프로필 사진 | `profileImage` | 프로필에 보이는 이미지 | 아바타 |
| 게임 계정·티어 | `GameAccount`, `tier` | 회원이 직접 입력하는 게임 계정 이름과 등급. 검증하지 않는다 | |
| 계정 공개 범위 | `AccountVisibility` | 공개(PUBLIC) 또는 비공개(PRIVATE) | 프라이버시 설정 |
| 탈퇴 / 탈퇴 유예 | `withdraw` / `withdrawalGracePeriod` | 회원이 계정을 닫는 일과, 파기 전 관리자 복구가 가능한 기간 | 휴면, 삭제 |
| 재가입 제한 | `rejoinRestriction` | 파기된 계정의 휴대폰 번호로 일정 기간 다시 가입하지 못하게 하는 제한 | |
| 찾을 수 없는 회원 | `UnavailableMember` | 탈퇴·정지 회원이나 나를 차단한 회원처럼 프로필·검색·목록에서 보이지 않는 회원 | 숨김 회원 |
