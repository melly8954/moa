# 문자 발송

| ID | 요구 | 기준 | 확인 방법 | 적용 범위 | 우선순위 |
|---|---|---|---|---|---|
| INT-SMS-001 | 가입 때 휴대폰 번호 인증 문자를 보낸다 <!-- ck-int-1 --> | 문자 발송 서비스는 설계에서 고른다. 개발 환경은 실제 문자 대신 로그로 출력한다 | 개발 환경에서 인증 번호가 로그에 나오고, 운영 설정에서 실제 문자가 온다 | 개별 | must |
| INT-SMS-002 | 발송에 실패하면 알린다 <!-- ck-int-2 --> | 발송 실패 시 화면에 실패를 알리고 다시 보내기를 제공한다. 다시 보내기는 60초에 한 번, 한 번호에 하루 10회까지 | 61초 전 재요청과 11번째 요청이 거부된다 | 개별 | must |
