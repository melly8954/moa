# 소셜 로그인

| ID | 요구 | 기준 | 확인 방법 | 적용 범위 | 우선순위 |
|---|---|---|---|---|---|
| INT-GOOGLE-001 | 구글 계정으로 가입·로그인한다 <!-- ck-int-1 --> | OAuth 2.0 / OpenID Connect로 인증하고 이메일을 받는다 | 구글 테스트 계정으로 가입·로그인한다 | 개별 | must |
| INT-GOOGLE-002 | 같은 이메일의 기존 계정에 합칠 때는 구글이 인증된 이메일로 알려 준 경우만 합친다 | email_verified가 true일 때만 합친다 | email_verified가 false인 응답을 흉내 내면 합치지 않는다 | 개별 | must |
| INT-KAKAO-001 | 카카오 계정으로 가입·로그인한다 <!-- ck-int-1 --> | 카카오 로그인(OAuth 2.0)으로 인증하고 이메일을 받는다 | 카카오 테스트 계정으로 가입·로그인한다 | 개별 | must |
| INT-KAKAO-003 | 카카오가 이메일을 주지 않아도 가입할 수 있다 | 이메일 제공 동의를 하지 않으면 이메일 가입 단계로 이어 가 이메일을 인증받는다 〔2026-09-25〕 사용자 결정 | 이메일 동의를 끈 카카오 테스트 계정으로 가입한다 | 개별 | must |
| INT-KAKAO-002 | 같은 이메일의 기존 계정에 합칠 때는 카카오가 인증된 이메일로 알려 준 경우만 합친다 | 이메일 인증 여부(`is_email_verified`)와 유효 여부(`is_email_valid`)가 모두 참일 때만 합친다 〔2026-10-04〕 사용자 결정. 유효하지 않은 이메일은 다른 사람에게 넘어갔을 수 있다 | 인증 여부나 유효 여부가 거짓인 응답을 흉내 내면 합치지 않는다 | 개별 | must |

<!-- ck-int-2 --> 구글·카카오 인증이 실패하거나 응답이 없으면 가입·로그인 화면으로 돌아가 다른 수단을 쓰게 한다 (FR-MEM-001, FR-MEM-002 예외 흐름)
