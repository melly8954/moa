# 메일 발송

| ID | 요구 | 기준 | 확인 방법 | 적용 범위 | 우선순위 |
|---|---|---|---|---|---|
| INT-MAIL-001 | 가입 인증 메일과 비밀번호 재설정 메일을 보낸다 <!-- ck-int-1 --> | 처음에는 SMTP로 보내고, 안정화되면 메일 발송 서비스(AWS SES 등)로 바꾼다. 발송 수단은 설정으로 바꾸고 기능 코드는 고치지 않는다 | 설정만 바꿔 SMTP와 테스트용 발송 수단 두 가지로 메일이 나가는지 본다 | 개별 | must |
| INT-MAIL-002 | 발송에 실패하면 알린다 <!-- ck-int-2 --> | 발송 실패 시 화면에 실패를 알리고 다시 보내기를 제공한다. 다시 보내기는 60초에 한 번 | 발송 서버를 끊은 상태에서 실패 안내가 나오고, 60초 안에 다시 보내기가 막힌다 | 개별 | must |
