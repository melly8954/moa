# 역할과 권한

- 값: `○` 허용, `-` 불가, `△` 조건부 (조건은 각 표 아래에 적는다)
- FR 파일의 행위자는 주 흐름을 수행하는 주체만 적는다. 누가 허용되는지는 이 파일에만 적는다

## 역할

<!-- ck-act-1 -->
<!-- ck-act-4 --> 관리자 등급은 나누지 않는다. 개인 프로젝트로 운영자가 한 명이다

| 역할 | 설명 | 로그인 필요 |
|---|---|---|
| 비회원 | 로그인하지 않은 방문자 | 아니오 |
| 회원 | 가입한 사용자. 게이머와 게임 관련 직업인을 같은 역할로 둔다 | 예 |
| 관리자 | 신고 처리, 회원 제재·해제, 탈퇴 계정 복구, 게임 목록 관리. 회원 활동(글쓰기, 파티, 메시지)은 하지 않고 조회만 한다 〔2026-09-25〕 사용자 결정 | 예 |

## 역할별 요약

<!-- ck-act-3 -->
- 비회원: 공개 피드, 게시물, 프로필, 파티 모집 목록을 읽기만 한다. 쓰기, 반응, 메시지는 로그인해야 한다

<!-- ck-act-2 -->
- 회원: 친구(맞팔)가 아닌 사람은 파티에 초대할 수 없다. 1:1 메시지는 친구가 아니어도 보낼 수 있다 〔2026-09-25〕 인터뷰에서 비친구 메시지 불가로 정했으나 사용자가 인스타그램 DM처럼 누구나로 변경. 계정을 비공개로 할 수 있고, 다른 회원을 차단할 수 있다
