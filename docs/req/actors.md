# 역할과 권한

- 값: `○` 허용, `-` 불가, `△` 조건부 (조건은 각 표 아래에 적는다)
- FR 파일의 행위자는 주 흐름을 수행하는 주체만 적는다. 누가 허용되는지는 이 파일에만 적는다

## 역할

<!-- ck-act-1 -->
<!-- ck-act-4 --> 관리자 등급은 나누지 않는다. 개인 프로젝트로 운영자가 한 명이다

| 역할 | 설명 | 로그인 필요 |
|---|---|---|
| 비회원 | 로그인하지 않은 방문자 | 아니오 |
| 회원 | 가입한 사용자. 게이머와 게임 관련 직업인을 같은 역할로 둔다 | 예 |
| 관리자 | 신고 처리, 게시물 숨김, 회원 제재, 게임 목록 관리 | 예 |

## 역할별로 할 수 있는 것과 없는 것

<!-- 권한 매트릭스는 psw-req가 기능 ID로 채운다. 아래는 인터뷰 답이다 -->

<!-- ck-act-3 -->
- 비회원: 공개 피드, 게시물, 프로필, 파티 모집 목록을 읽기만 한다. 쓰기, 반응, 메시지는 로그인해야 한다

<!-- ck-act-2 -->
- 회원
  - 친구(맞팔)가 아닌 사람에게는 메시지를 보내거나 파티 초대를 할 수 없다
  - 계정을 비공개로 할 수 있다. 비공개 계정은 팔로우 요청을 승인받은 사람에게만 글이 보인다
  - 다른 회원을 차단할 수 있다. 차단당한 사람은 나를 팔로우하거나, 나에게 메시지를 보내거나, 나를 초대할 수 없다
