# FR-REL-005 차단·차단 해제

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 다른 회원의 프로필에서 차단을 누르고 확인한다
2. 시스템이 차단한다
3. 회원이 차단 목록에서 차단을 풀 수 있다

## 예외 흐름

- E1. 확인 단계에서 취소하면 → 차단하지 않는다

## 수용 기준

- AC-1 [MUST] API: 차단하면 두 회원 사이의 팔로우와 대기 중인 팔로우 요청이 모두 없어진다
- AC-2 [MUST] API: 차단당한 회원의 팔로우, 1:1 메시지, 파티 초대 요청은 거부된다
- AC-3 [MUST] API: 차단당한 회원이 차단한 회원의 프로필·게시물·모집 글을 조회하면 찾을 수 없음으로 응답한다
- AC-4 [MUST] API: 차단을 풀어도 팔로우는 되살아나지 않는다
