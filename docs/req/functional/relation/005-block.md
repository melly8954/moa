# FR-REL-005 차단·차단 해제

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 다른 회원의 프로필에서 차단을 누르고 확인한다
2. 시스템이 차단하고 서로의 팔로우를 끊는다
3. 회원이 차단 목록에서 차단을 해제할 수 있다

## 예외 흐름

- E1. 확인 단계에서 취소하면 → 차단하지 않는다
- E2. 차단을 해제해도 → 끊긴 팔로우는 되살리지 않는다
