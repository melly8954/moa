# FR-REL-004 친구 목록 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 친구 목록을 연다
2. 시스템이 서로 팔로우한 회원 목록을 보여 준다
3. 회원이 친구를 골라 1:1 메시지나 파티 초대로 이어간다

## 예외 흐름

- E1. 친구가 없으면 → 회원 검색과 게임별 피드로 가는 안내를 보여 준다

## 수용 기준

- AC-1 [MUST] API: 친구 목록에는 서로 팔로우한 회원만 나온다
- AC-2 [MUST] 화면: 친구 항목에서 메시지와 파티 초대로 갈 수 있다
