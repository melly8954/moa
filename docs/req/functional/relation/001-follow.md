# FR-REL-001 팔로우·언팔로우

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 다른 회원의 프로필이나 게시물에서 팔로우를 누른다
2. 공개 계정이면 시스템이 바로 팔로우하고 상대에게 알림을 보낸다
3. 이미 팔로우 중이면 언팔로우를 눌러 끊는다

## 예외 흐름

- E1. 상대가 비공개 계정이면 → 팔로우 요청을 보내고 요청 중으로 표시한다 (FR-REL-002)
- E2. 상대가 나를 차단했으면 → 팔로우할 수 없다
- E3. 자기 자신은 → 팔로우할 수 없다
