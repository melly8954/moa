# FR-REL-002 팔로우 요청 승인·거절

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (비공개 계정)

## 선행조건

- 로그인한 상태다
- 비공개 계정이다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 받은 팔로우 요청 목록을 연다
2. 회원이 요청마다 승인하거나 거절한다
3. 승인하면 시스템이 팔로우를 맺고 요청자에게 알린다

## 예외 흐름

- E1. 거절하면 → 요청을 지운다. 요청자에게 알리지 않는다
- E2. 요청자가 그사이 요청을 취소했으면 → 목록에서 사라진다

## 수용 기준

- AC-1 [MUST] API: 승인하면 요청자의 팔로우가 맺어지고 요청이 없어진다
- AC-2 [MUST] API: 거절하면 요청이 없어지고 요청자에게 알림이 생기지 않는다
