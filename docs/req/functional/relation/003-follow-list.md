# FR-REL-003 팔로워·팔로잉 목록 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 프로필에서 팔로워 또는 팔로잉 수를 누른다
2. 시스템이 목록을 보여 준다

## 예외 흐름

- E1. 비공개 계정이고 승인된 팔로워가 아니면 → 목록을 보여 주지 않는다

## 수용 기준

- AC-1 [MUST] API: 비공개 계정의 팔로워·팔로잉 목록을 승인된 팔로워가 아닌 사용자가 요청하면 거부된다
- AC-2 [MUST] API: 목록에 찾을 수 없는 회원이 나오지 않는다

- `_policy.md` 차단 효과
