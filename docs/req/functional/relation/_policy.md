# 관계 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 관계 모델 | 팔로우만 둔다. 서로 팔로우하면(맞팔) 친구다. 별도 친구 요청은 없다 | 〔2026-09-25〕 팔로우·친구를 둘 다 두는 안을 추천했으나 사용자가 인스타그램형으로 결정 |
| 친구만 할 수 있는 것 | 1:1 메시지 시작, 파티 초대 | 인터뷰 답 (ck-act-2) |
| 팔로우 요청 | 비공개 계정을 팔로우하면 요청이 되고, 상대가 승인해야 팔로우가 맺어진다. 거절은 요청자에게 알리지 않는다 | 인터뷰 답 (ck-act-2) |
| 차단 효과 | 차단하면 서로의 팔로우와 대기 중인 팔로우 요청을 끊는다. 차단당한 사람은 차단한 사람을 팔로우·메시지·초대할 수 없고, 차단한 사람의 프로필·게시물·모집 글을 볼 수 없다. 차단을 풀어도 끊긴 팔로우는 되살리지 않는다 | 인터뷰 답 (ck-act-2) |
