# FR-PTY-008 파티 나가기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (파티원)

## 선행조건

- 로그인한 상태다
- 파티원이다

## 주 흐름

<!-- ck-fun-3 -->

1. 파티원이 나가기를 누르고 확인한다
2. 시스템이 파티와 채팅방에서 빼고 남은 파티원에게 알린다
3. 시스템이 남은 파티원 평가(FR-REP-001)로 이어 준다

## 예외 흐름

- E1. 방장이고 다른 파티원이 있으면 → 나갈 수 없다. 방장 넘기기(FR-PTY-009)를 먼저 하라고 안내한다
- E2. 혼자 남은 방장이면 → 나가면 파티가 없어진다고 알리고 확인받는다
- E3. 확인에서 취소하면 → 나가지 않는다

## 수용 기준

- AC-1 [MUST] API: 나간 회원은 파티 채팅방을 읽고 쓸 수 없다
- AC-2 [MUST] API: 다른 파티원이 있는 방장의 나가기는 거부된다
- AC-3 [MUST] API: 혼자 남은 방장이 나가면 파티가 없어지고 열린 모집은 CANCELED가 된다
- AC-4 [MUST] 화면: 나간 직후 평가할 파티원 목록이 보인다
