# 파티 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치, 상태 전이다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 파티 | 채팅방이 있는 모임이다. 게임을 같이 하려고 만들 수도 있고, 친구끼리 이야기만 하는 단톡방으로 써도 된다. 해산 기능은 없고, 마지막 파티원이 나가면 없어진다 | 〔2026-09-25〕 사용자 결정. 그룹 대화방을 파티로 합침 |
| 파티 이름 | 1~30자 | 〔2026-09-25〕 사용자 결정 |
| 최대 인원 | 방장이 2~50명 사이에서 정한다 | 〔2026-09-25〕 사용자 결정 |
| 파티 게임 | 파티에는 게임을 고르지 않아도 된다. 모집을 열 때는 게임이 필수다 | 〔2026-09-25〕 사용자 결정 |
| 동시 소속 | 한 회원이 여러 파티의 방장이나 파티원이 될 수 있다. 제한이 없다 | 〔2026-09-25〕 한 번에 한 파티를 추천했으나 사용자가 제한 없음으로 결정 |
| 방장 | 파티를 만든 회원. 방장만 모집을 열고 마감·취소하고, 참여 신청을 수락·거절하고, 파티원을 내보내고, 방장을 넘긴다 | 〔2026-09-25〕 사용자 결정 |
| 방장 퇴장 | 다른 파티원이 있으면 방장을 넘겨야 나갈 수 있다. 혼자 남은 방장이 나가면 파티가 없어진다 | 〔2026-09-25〕 먼저 들어온 사람에게 자동 위임을 추천했으나 사용자가 직접 양도 후 퇴장으로 결정 |
| 모집 | 파티마다 열린 모집은 하나. 게임(필수), 모드, 티어 범위, 구하는 인원, 설명, 참여 방식을 적는다. 구하는 인원은 남은 자리 수 이하다. 친구가 아니어도 참여할 수 있다 | 인터뷰 답 |
| 모집 설명 | 최대 500자 | 〔2026-09-25〕 사용자 결정 |
| 참여 방식 | 방장이 모집마다 즉시 참여(선착순)와 승인제 중에서 고른다 | 〔2026-09-25〕 승인제만 두는 안을 추천했으나 사용자가 모집마다 선택으로 결정 |
| 모집 만료 | 모집을 연 뒤 24시간이 지나면 자동으로 만료된다. 파티는 남는다 | 〔2026-09-25〕 사용자 결정 |
| 초대 | 파티원 누구나 친구를 초대할 수 있다. 초대받은 친구가 수락하면 들어온다. 수락은 초대받은 본인만, 수락할 때 자리가 남아 있어야 한다 〔2026-10-02〕 사용자 결정. 열린 모집이 승인제면 수락한 뒤 방장 승인을 거친다 | 〔2026-09-25〕 방장만 초대를 추천했으나 사용자가 파티원 누구나로 결정 |
| 모드·티어 선택지 | 관리자 게임 목록(FR-ADM-004)을 따른다 | 인터뷰 답 |

## 상태 전이: 모집

<!-- 상태값의 정본은 이 절이다. 코드의 상태 이름은 이 절을 따른다 -->

### 상태

| 상태 | 의미 |
|---|---|
| OPEN | 모집 중. 모집 목록에 보인다 |
| FILLED | 성사. 구하는 인원이 찼거나 방장이 마감했다 |
| CANCELED | 방장이 취소했다 |
| EXPIRED | 모집 만료 시간이 지났다 |

### 전이

| (없음) | 모집 열기 | OPEN | 열린 모집이 없고 남은 자리가 있다 | 방장 | 모집 목록에 올림 | FR-PTY-010 |

| OPEN | 마감 | FILLED | | 방장 | 위와 같다 | FR-PTY-006 |
| OPEN | 취소 | CANCELED | | 방장 | 모집 목록에서 내림, 대기 중인 참여 신청 거절 | FR-PTY-006 |
| OPEN | 만료 시간 경과 | EXPIRED | | 시스템 | 모집 목록에서 내림, 대기 중인 참여 신청 거절 | FR-PTY-010 |
