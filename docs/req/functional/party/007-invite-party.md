# FR-PTY-007 친구를 파티에 초대

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (파티원)

## 선행조건

- 로그인한 상태다
- 모집 중인 파티의 파티원이다

## 주 흐름

<!-- ck-fun-3 -->

1. 파티원이 친구를 고르고 초대한다
2. 초대받은 친구가 수락하면 시스템이 파티원으로 넣고 채팅방에 들인다

## 예외 흐름

- E1. 인원이 찼으면 → 초대할 수 없다
- E2. 초대받은 친구가 거절하거나 응답하지 않으면 → 넣지 않는다
- E3. 승인제 파티면 → 친구가 수락해도 바로 넣지 않고 방장의 승인(FR-PTY-004)을 거친다
