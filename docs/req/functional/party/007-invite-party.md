# FR-PTY-007 친구를 파티에 초대

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (파티원)

## 선행조건

- 로그인한 상태다
- 파티원이다

## 주 흐름

<!-- ck-fun-3 -->

1. 파티원이 친구를 골라 초대한다
2. 초대받은 친구가 수락하면 시스템이 파티원으로 넣고 채팅방에 들인다

## 예외 흐름

- E1. 파티가 최대 인원이면 → 초대할 수 없다
- E2. 친구가 아니거나 나를 차단한 회원이면 → 초대할 수 없다
- E3. 초대받은 친구가 거절하면 → 넣지 않는다
- E4. 열린 모집이 승인제면 → 친구가 수락한 뒤 방장 승인(FR-PTY-004)을 거친다

## 수용 기준

- AC-1 [MUST] API: 친구를 초대하고 친구가 수락하면 파티원이 된다
- AC-2 [MUST] API: 친구가 아닌 회원, 나를 차단한 회원에 대한 초대는 거부된다
- AC-3 [MUST] API: 최대 인원인 파티의 초대는 거부된다
- AC-4 [MUST] API: 승인제 모집이 열린 파티에서는 초대를 수락해도 방장 승인 전까지 파티원이 아니다
