# FR-PTY-006 모집 마감·취소

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (방장)

## 선행조건

- 로그인한 상태다
- 방장이다
- 모집 중인 파티다

## 주 흐름

<!-- ck-fun-3 -->

1. 방장이 마감 또는 취소를 누른다
2. 마감이면 시스템이 파티를 성사로 바꾸고 모집 목록에서 내린다
3. 취소면 시스템이 파티를 취소하고 파티원에게 알린다

## 예외 흐름

- E1. 인원이 다 차면 → 방장이 누르지 않아도 성사로 바뀐다
