# FR-PTY-002 파티 모집 목록 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 파티 모집 목록을 연다
2. 사용자가 게임, 모드, 티어로 거른다
3. 시스템이 모집 중인 글을 최신순으로 보여 준다

## 예외 흐름

- E1. 결과가 없으면 → 모집 글 쓰기 안내를 보여 준다
- E2. 나를 차단한 방장의 글은 → 보여 주지 않는다
