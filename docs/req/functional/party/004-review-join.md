# FR-PTY-004 참여 신청 수락·거절

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (방장)

## 선행조건

- 로그인한 상태다
- 방장이다

## 주 흐름

<!-- ck-fun-3 -->

1. 방장이 신청자 목록에서 프로필·티어·평판을 본다
2. 방장이 수락하거나 거절한다
3. 수락하면 시스템이 신청자를 파티원으로 넣고 채팅방에 들인 뒤 알린다

## 예외 흐름

- E1. 거절하면 → 신청을 지우고 신청자에게 알린다
- E2. 수락하려는데 구하는 인원이 찼으면 → 수락할 수 없다

## 수용 기준

- AC-1 [MUST] API: 수락하면 신청자가 파티원이 되고 신청자에게 알림이 생긴다
- AC-2 [MUST] API: 거절하면 신청이 없어지고 신청자에게 알림이 생긴다
- AC-3 [MUST] API: 방장이 아닌 회원의 수락·거절은 거부된다
