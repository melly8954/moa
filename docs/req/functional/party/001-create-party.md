# FR-PTY-001 파티 모집 글 작성

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (방장)

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게임, 모드, 티어 범위, 인원, 설명을 입력한다
2. 회원이 참여 방식(즉시 참여 또는 승인제)을 고른다
3. 시스템이 모집 글을 올리고 파티 채팅방을 연다. 작성자가 방장이 된다
