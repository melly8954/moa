# FR-PTY-010 모집 열기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (방장)

## 선행조건

- 로그인한 상태다
- 방장이다

## 주 흐름

<!-- ck-fun-3 -->

1. 방장이 게임, 모드, 티어 범위, 구하는 인원, 설명, 참여 방식을 입력한다
2. 시스템이 OPEN 모집을 만들어 모집 목록에 올린다

## 예외 흐름

- E1. 이미 OPEN 모집이 있으면 → 새로 열 수 없다
- E2. 게임이 없거나 구하는 인원이 남은 자리보다 많으면 → 열지 않는다
- E3. 설명이 길이 규칙을 넘으면 → 열지 않는다

## 수용 기준

- AC-1 [MUST] API: 규칙에 맞게 열면 OPEN 모집이 생기고 모집 목록에 나온다
- AC-2 [MUST] API: OPEN 모집이 이미 있는 파티, 게임이 없는 요청, 남은 자리보다 많은 인원 요청은 거부된다
- AC-3 [MUST] API: 방장이 아닌 회원의 요청은 거부된다
- AC-4 [MUST] API: 모집 만료 시간이 지난 OPEN 모집은 EXPIRED가 되고 목록에서 사라진다
