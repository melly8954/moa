# FR-PTY-003 파티 참여

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다
- OPEN 모집이 있는 파티다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 모집 글에서 참여를 누른다
2. 즉시 참여면 시스템이 바로 파티원으로 넣고 파티 채팅방에 들인다
3. 승인제면 참여 신청을 방장에게 보내고 신청 중으로 표시한다
4. 구하는 인원이 차면 시스템이 모집을 FILLED로 바꾼다

## 예외 흐름

- E1. 이미 파티원이면 → 파티 채팅방을 연다
- E2. 구하는 인원이 이미 찼으면 → 참여할 수 없다
- E3. 방장이 나를 차단했으면 → 참여할 수 없다
- E4. 신청 중에 취소하면 → 신청을 지운다

## 수용 기준

- AC-1 [MUST] API: 즉시 참여 모집에 참여하면 파티원이 되고 파티 채팅방을 읽고 쓸 수 있다
- AC-2 [MUST] API: 승인제 모집에 참여하면 파티원이 아니라 신청이 생긴다
- AC-3 [MUST] API: 마지막 자리가 채워지면 모집이 FILLED가 되고 목록에서 사라진다
- AC-4 [MUST] API: OPEN이 아닌 모집, 인원이 찬 모집, 나를 차단한 방장의 모집에는 참여가 거부된다
