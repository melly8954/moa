# FR-PTY-003 파티 참여

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다
- 모집 중인 파티다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 모집 글에서 참여를 누른다
2. 즉시 참여 방식이면 시스템이 바로 파티원으로 넣고 파티 채팅방에 들인다
3. 승인제면 참여 신청을 방장에게 보내고 신청 중으로 표시한다

## 예외 흐름

- E1. 인원이 이미 찼으면 → 참여할 수 없다
- E2. 방장이 나를 차단했으면 → 참여할 수 없다
- E3. 신청 중에 취소하면 → 신청을 지운다
