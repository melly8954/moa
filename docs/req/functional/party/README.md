## 정책 후보

<!-- 인터뷰에서 나온 규칙·수치 후보다. psw-req가 _policy.md로 옮기고 이 절을 지운다 -->

- 참여 방식은 방장이 모집 글마다 즉시 참여(선착순)와 승인제 중에서 고른다 〔2026-09-25〕 승인제만 두는 안을 추천했으나 사용자가 글마다 선택으로 결정
- 한 회원이 동시에 여러 파티의 방장이나 파티원이 될 수 있다. 제한이 없다 〔2026-09-25〕 한 번에 한 파티를 추천했으나 사용자가 제한 없음으로 결정
- 방장은 방장을 다른 파티원에게 넘겨야 파티를 나갈 수 있다 〔2026-09-25〕 먼저 들어온 사람에게 자동 위임을 추천했으나 사용자가 직접 양도 후 퇴장으로 결정
- 파티원 누구나 친구를 파티에 초대할 수 있다. 승인제 파티면 초대받은 사람도 방장 승인이 필요하다 〔2026-09-25〕 방장만 초대를 추천했으나 사용자가 파티원 누구나로 결정
- 모집 글은 친구가 아니어도 참여할 수 있다. 파티 초대는 친구에게만 한다
- 인원이 다 차거나 방장이 마감하면 파티가 성사된다. 성사된 뒤 일정 시간이 지나면 평판 평가가 열린다 (시간 값은 psw-req에서 정한다)
- 파티 상태 후보: 모집 중 → 성사 → 평가 가능 → 종료, 모집 중 → 취소
- 게임별 모드·티어 값은 관리자가 게임 목록에서 관리한다 (FR-ADM-004)
