# FR-FEED-005 좋아요

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게시물에 좋아요를 누른다
2. 시스템이 좋아요를 기록하고 작성자에게 알린다
3. 다시 누르면 좋아요를 취소한다

## 예외 흐름

- E1. 비회원이 누르면 → 로그인 화면으로 보낸다

## 수용 기준

- AC-1 [MUST] API: 한 회원은 한 게시물에 좋아요를 한 번만 할 수 있고, 다시 요청하면 취소된다
- AC-2 [MUST] API: 좋아요를 하면 작성자에게 알림이 생긴다. 자기 글이면 생기지 않는다
- AC-3 [MUST] API: 비회원의 좋아요 요청은 거부된다
