# 피드 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 게시물 게임 | 게시물마다 게임을 하나 고른다. 선택지는 관리자 게임 목록(FR-ADM-004)을 따른다 | 인터뷰 답 |
| 게시물 길이 | 본문 최대 2,000자, 해시태그 최대 10개 | 〔2026-09-25〕 사용자 결정 |
| 댓글 길이 | 최대 500자 | 〔2026-09-25〕 사용자 결정 |
| 첨부 규칙 | 이미지: JPG·PNG·GIF·WEBP, 한 장에 최대 10MB, 최대 10장. 동영상: MP4·WEBM, 최대 60초·100MB, 1개. 게시물 하나에는 이미지와 동영상 중 한 종류만 붙인다. 메신저도 이 규칙을 쓴다 | 〔2026-09-25〕 사용자 결정 |
| 외부 링크 클립 | 유튜브·치지직 등 영상 링크 1개를 붙일 수 있다. 미리보기를 가져오지 못하면 주소만 보여 준다 | 〔2026-09-25〕 직접 업로드만을 추천했으나 사용자가 업로드와 링크 둘 다로 결정 |
| 게시물 공개 범위 | 작성자 계정의 공개 범위를 따른다. 게시물마다 고르지 않는다 | 인터뷰 답 |
| 보이지 않는 게시물 | 찾을 수 없는 회원의 게시물, 비공개 계정의 게시물(승인된 팔로워가 아니면), 관리자가 숨긴 게시물(작성자가 아니면) | 인터뷰 답, 회원·관계 정책 |
| 홈 피드 구성 | 팔로우한 회원의 게시물을 최신순으로 보여 주고, 4개마다 추천 글 1개를 넣는다 | 〔2026-09-25〕 팔로우만 최신순을 추천했으나 사용자가 추천 글 포함으로 결정 |
| 추천 글 | 내가 플레이하는 게임의 최근 7일 공개 게시물 중 (좋아요 수 + 댓글 수 × 2)가 큰 순. 팔로우한 회원의 글과 내 글은 뺀다. 플레이하는 게임이 없으면 모든 게임에서 고른다. 나중에 AI 추천(FR-MAT-004)으로 바꾼다 | 〔2026-09-25〕 사용자 결정 |
| 목록 정렬 | 게임별 피드·해시태그 검색은 최신순 | 인터뷰 답 |
| 신고 사유 | 스팸·광고, 욕설·비하, 음란물·불법 촬영물, 도배, 개인정보 노출, 기타(직접 입력) | 〔2026-09-25〕 사용자 결정 |
| 중복 신고 | 한 회원이 같은 대상을 한 번만 신고한다 | 〔2026-09-25〕 사용자 결정 |
| 댓글 삭제 권한 | 댓글 작성자와 게시물 작성자 | 인터뷰 답 |
