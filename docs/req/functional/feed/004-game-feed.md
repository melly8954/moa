# FR-FEED-004 게임별 피드 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 게임을 고른다
2. 시스템이 그 게임의 게시물을 최신순으로 보여 준다
3. 사용자가 아래로 내리면 이어서 불러온다

## 예외 흐름

- E1. 게시물이 없으면 → 첫 글 쓰기 안내를 보여 준다 (비회원에게는 로그인 안내)

## 수용 기준

- AC-1 [MUST] API: 고른 게임의 게시물만 최신순으로 나온다
- AC-2 [MUST] API: 보이지 않는 게시물은 나오지 않는다
- AC-3 [MUST] API: 비회원도 조회할 수 있다

## 정책 참조

- `_policy.md` 목록 정렬
- `_policy.md` 보이지 않는 게시물
