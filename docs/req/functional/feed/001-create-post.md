# FR-FEED-001 게시물 작성

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게임을 하나 고른다
2. 회원이 글을 쓰고 이미지나 클립(파일 업로드 또는 외부 링크)을 붙인다
3. 회원이 해시태그를 넣는다
4. 시스템이 게시물을 저장하고 홈 피드와 게임별 피드에 올린다

## 예외 흐름

- E1. 게임을 고르지 않으면 → 게시하지 않는다
- E2. 파일 형식·길이·용량이 맞지 않으면 → 해당 파일을 올리지 않고 사유를 알린다
- E3. 외부 링크를 미리보기로 가져오지 못하면 → 링크 주소만 보여 준다
- E4. 업로드 중에 취소하면 → 게시물을 만들지 않는다
