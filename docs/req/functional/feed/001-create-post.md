# FR-FEED-001 게시물 작성

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게임을 고른다
2. 회원이 본문을 쓰고 이미지나 동영상을 올리거나 영상 링크를 붙인다
3. 회원이 해시태그를 넣는다
4. 시스템이 게시물을 저장하고 팔로워의 홈 피드와 게임별 피드에 올린다

## 예외 흐름

- E1. 게임을 고르지 않았으면 → 게시하지 않는다
- E2. 본문·해시태그·첨부가 규칙에 맞지 않으면 → 게시하지 않고 사유를 알린다
- E3. 본문과 첨부가 모두 비었으면 → 게시하지 않는다
- E4. 업로드 중에 취소하면 → 게시물을 만들지 않는다

## 수용 기준

- AC-1 [MUST] API: 게임, 본문, 규칙에 맞는 첨부로 게시하면 게임별 피드 첫 항목에 나온다
- AC-2 [MUST] API: 게임이 없거나 게시물 길이 규칙(본문 길이, 해시태그 수)을 넘으면 거부된다
- AC-3 [MUST] API: 첨부 규칙을 넘는 첨부(이미지 장수·용량, 동영상 길이·용량·개수, 형식)는 거부된다
- AC-4 [MUST] API: 이미지와 동영상을 함께 붙이면 거부된다
- AC-5 [SHOULD] 화면: 영상 링크를 붙이면 미리보기가 보이고, 가져오지 못하면 주소가 보인다
