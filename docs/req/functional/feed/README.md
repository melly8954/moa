## 정책 후보

<!-- 인터뷰에서 나온 규칙·수치 후보다. psw-req가 _policy.md로 옮기고 이 절을 지운다 -->

- 게시물에는 게임을 하나 고른다 (리그 오브 레전드, 오버워치, 배틀그라운드). 게임별 피드는 이 값으로 모은다
- <!-- ck-fun-6 --> 클립은 직접 업로드와 외부 링크(유튜브, 치지직 등)를 모두 허용한다 〔2026-09-25〕 직접 업로드만을 추천했으나 사용자가 둘 다로 결정
- 홈 피드는 팔로우한 사람의 글과 추천 글을 섞는다 〔2026-09-25〕 팔로우만 최신순을 추천했으나 사용자가 추천 글 포함으로 결정. 추천 글은 내가 플레이하는 게임의 인기 글(최근 좋아요·댓글 수)로 시작하고, 나중에 AI 추천(FR-MAT-004)으로 바꾼다 〔2026-09-25〕 선택지 중 사용자가 결정
- 업로드 영상의 길이·용량, 이미지 개수·용량 제한은 psw-req에서 정한다
- 게시물 공개 범위는 계정 공개 범위를 따른다
