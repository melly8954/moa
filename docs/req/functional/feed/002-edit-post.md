# FR-FEED-002 게시물 수정·삭제

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (작성자)

## 선행조건

- 로그인한 상태다
- 자기 게시물이다

## 주 흐름

<!-- ck-fun-3 -->

1. 작성자가 게시물을 열어 수정 또는 삭제를 고른다
2. 수정이면 글, 첨부, 해시태그를 고쳐 저장한다
3. 삭제면 확인 후 시스템이 게시물을 피드에서 내린다

## 예외 흐름

- E1. 관리자가 숨긴 게시물이면 → 수정할 수 없다
- E2. 삭제 확인에서 취소하면 → 삭제하지 않는다
