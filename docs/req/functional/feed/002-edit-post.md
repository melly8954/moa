# FR-FEED-002 게시물 수정·삭제

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (작성자)

## 선행조건

- 로그인한 상태다
- 자기 게시물이다

## 주 흐름

<!-- ck-fun-3 -->

1. 작성자가 게시물에서 수정 또는 삭제를 고른다
2. 수정이면 본문, 첨부, 해시태그, 게임을 고쳐 저장한다
3. 삭제면 확인 후 시스템이 게시물과 댓글을 지운다

## 예외 흐름

- E1. 관리자가 숨긴 게시물이면 → 수정할 수 없다. 삭제는 할 수 있다
- E2. 삭제 확인에서 취소하면 → 지우지 않는다

## 수용 기준

- AC-1 [MUST] API: 작성자가 아닌 회원의 수정·삭제 요청은 거부된다
- AC-2 [MUST] API: 수정할 때도 게시물 길이·첨부 규칙이 적용된다
- AC-3 [MUST] API: 삭제한 게시물은 모든 피드와 검색 결과에서 사라진다
- AC-4 [MUST] API: 숨긴 게시물의 수정은 거부된다
