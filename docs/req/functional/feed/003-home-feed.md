# FR-FEED-003 홈 피드 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 홈을 연다
2. 시스템이 홈 피드 구성 규칙대로 게시물을 보여 준다
3. 회원이 아래로 내리면 이어서 불러온다

## 예외 흐름

- E1. 팔로우한 회원이 없거나 새 글이 없으면 → 추천 글만 보여 준다

## 수용 기준

- AC-1 [MUST] API: 팔로우한 회원의 게시물이 최신순으로 나오고, 홈 피드 구성 규칙의 간격마다 추천 글이 들어간다
- AC-2 [MUST] API: 추천 글에는 팔로우한 회원의 글과 내 글이 없다
- AC-3 [MUST] API: 보이지 않는 게시물은 나오지 않는다
- AC-4 [MUST] 화면: 추천 글에는 추천 글이라는 표시가 있다

- `_policy.md` 홈 피드 구성
- `_policy.md` 추천 글
