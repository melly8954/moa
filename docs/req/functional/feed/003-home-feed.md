# FR-FEED-003 홈 피드 보기

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 홈을 연다
2. 시스템이 팔로우한 사람의 게시물과 추천 게시물을 섞어 보여 준다
3. 회원이 아래로 내리면 이어서 불러온다

## 예외 흐름

- E1. 팔로우한 사람이 없으면 → 추천 게시물만 보여 준다
- E2. 차단한·나를 차단한 회원의 글은 → 보여 주지 않는다
