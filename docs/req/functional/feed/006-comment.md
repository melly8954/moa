# FR-FEED-006 댓글 작성·삭제

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게시물에 댓글을 쓴다
2. 시스템이 댓글을 달고 게시물 작성자에게 알린다
3. 댓글 삭제 권한이 있는 회원은 댓글을 지울 수 있다

## 예외 흐름

- E1. 게시물 작성자가 나를 차단했으면 → 댓글을 쓸 수 없다
- E2. 빈 댓글이나 길이 규칙을 넘는 댓글은 → 등록하지 않는다

## 수용 기준

- AC-1 [MUST] API: 댓글 길이 안의 댓글은 등록되고 게시물 작성자에게 알림이 생긴다
- AC-2 [MUST] API: 빈 댓글과 댓글 길이를 넘는 댓글은 거부된다
- AC-3 [MUST] API: 댓글 작성자와 게시물 작성자가 아닌 회원의 삭제 요청은 거부된다

## 정책 참조

- `_policy.md` 댓글 길이
- `_policy.md` 댓글 삭제 권한
- `_policy.md` 차단 효과 (관계 정책)
