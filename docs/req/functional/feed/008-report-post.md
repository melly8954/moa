# FR-FEED-008 게시물·댓글 신고

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게시물이나 댓글에서 신고를 누르고 사유를 고른다
2. 시스템이 신고를 접수해 관리자 신고 목록에 올린다

## 예외 흐름

- E1. 같은 대상을 이미 신고했으면 → 다시 접수하지 않고 접수됐다고 알린다
- E2. 기타를 고르고 내용을 쓰지 않으면 → 접수하지 않는다

## 수용 기준

- AC-1 [MUST] API: 신고 사유 목록 중 하나로 신고하면 관리자 신고 목록에 생긴다
- AC-2 [MUST] API: 같은 회원이 같은 대상을 다시 신고하면 새 신고가 생기지 않는다
- AC-3 [MUST] API: 자기 글·댓글 신고는 거부된다
