# FR-FEED-007 해시태그 검색

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 해시태그를 입력하거나 게시물의 해시태그를 누른다
2. 시스템이 그 해시태그가 붙은 게시물을 최신순으로 보여 준다

## 예외 흐름

- E1. 결과가 없으면 → 결과 없음 안내를 보여 준다

## 수용 기준

- AC-1 [MUST] API: 해시태그가 정확히 일치하는 게시물만 최신순으로 나온다
- AC-2 [MUST] API: 보이지 않는 게시물은 나오지 않는다

## 정책 참조

- `_policy.md` 목록 정렬
- `_policy.md` 보이지 않는 게시물
