# FR-ADM-002 회원 제재

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

관리자

## 선행조건

- 관리자로 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 관리자가 회원을 골라 정지 기간과 사유를 입력한다
2. 시스템이 회원을 SUSPENDED로 바꾸고 모든 세션을 끊고 알린다

## 예외 흐름

- E1. 사유가 없으면 → 제재하지 않는다
- E2. 이미 정지된 회원이면 → 재제재 규칙대로 기간을 바꾼다

## 수용 기준

- AC-1 [MUST] API: 제재하면 회원이 SUSPENDED가 되고 기존 세션으로 한 요청이 거부된다
- AC-2 [MUST] API: 남은 정지가 2일인 회원에게 3일을 더하면 끝나는 날이 지금부터 5일 뒤가 된다
- AC-3 [MUST] API: 영구를 고르면 끝나는 날이 없어진다
- AC-4 [MUST] API: 사유 없는 제재는 거부된다
