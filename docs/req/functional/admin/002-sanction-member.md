# FR-ADM-002 회원 제재

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

관리자

## 선행조건

- 관리자로 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 관리자가 회원을 골라 정지 기간과 사유를 입력한다
2. 시스템이 회원을 정지하고 로그인 상태를 끊고 알린다

## 예외 흐름

- E1. 이미 정지된 회원이면 → 새 정지 기간을 남은 기간에 더한다 〔2026-09-25〕 새 기간으로 덮어쓰기를 추천했으나 사용자가 누적으로 결정
