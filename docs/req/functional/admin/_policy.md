# 관리 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치, 상태 전이다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 관리자 계정 | 관리 기능과 조회만 쓴다. 게시물 작성, 파티, 메시지 같은 회원 활동은 하지 않는다 | 〔2026-09-25〕 사용자 결정 |
| 관리자 계정 생성 | 배포 때 DB 마이그레이션 시드로 한 명을 만든다. 이메일과 비밀번호 해시는 저장소가 아니라 배포 환경변수로 넣는다. 첫 로그인 때 비밀번호 변경을 강제하지 않는다 | 〔2026-10-02〕 사용자 결정. 비밀번호를 저장소에 두지 않아 운영자만 알므로 강제 변경을 뺐다 |
| 관리자 등급 | 나누지 않는다 | 인터뷰 답 (ck-act-4) |
| 신고 처리 결과 | 숨김 또는 기각. 숨긴 게시물·댓글은 작성자에게만 숨김 표시와 함께 보인다 | 인터뷰 답 |
| 정지 기간 | 1일, 3일, 7일, 30일, 영구 중 고른다. 사유는 필수 | 〔2026-09-25〕 사용자 결정 |
| 재제재 | 정지 중에 다시 제재하면 남은 기간에 새 기간을 더한다. 영구를 고르면 영구로 바꾼다 | 〔2026-09-25〕 새 기간으로 덮어쓰기를 추천했으나 사용자가 누적으로 결정. 영구 처리는 사용자 결정 |
| 계정 복구 | 탈퇴 유예(회원 정책) 안의 WITHDRAWN 계정만 복구한다. 본인 확인은 관리자가 문의 채널에서 직접 한다 | 〔2026-09-25〕 사용자 결정 |
| 게임 목록 | 게임마다 모드와 티어 값을 둔다. 처음에는 리그 오브 레전드, 오버워치, 배틀그라운드 3종이다. 쓰이고 있는 게임·모드·티어는 지우지 않고 숨긴다 | 인터뷰 답 |
