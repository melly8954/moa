# FR-ADM-004 게임 목록 관리

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

관리자

## 선행조건

- 관리자로 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 관리자가 게임을 추가하거나 고친다
2. 관리자가 게임마다 모드와 티어 값을 관리한다
3. 시스템이 저장하고 게시물·파티·프로필의 선택지에 반영한다

## 예외 흐름

- E1. 이미 쓰이는 모드·티어를 지우려 하면 → 지우지 않고 숨김 처리한다
