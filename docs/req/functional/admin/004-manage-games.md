# FR-ADM-004 게임 목록 관리

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

관리자

## 선행조건

- 관리자로 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 관리자가 게임을 추가하거나 이름을 고친다
2. 관리자가 게임마다 모드와 티어 값을 추가·수정·정렬한다
3. 시스템이 저장하고 게시물·모집·프로필의 선택지에 반영한다

## 예외 흐름

- E1. 이미 쓰이는 게임·모드·티어를 지우려 하면 → 지우지 않고 숨긴다. 숨긴 값은 새로 고를 수 없고 기존 데이터에는 그대로 보인다

## 수용 기준

- AC-1 [MUST] API: 추가한 게임·모드·티어가 게시물·모집·프로필 선택지에 나온다
- AC-2 [MUST] API: 쓰이는 값을 지우면 숨김이 되고, 이후 그 값으로 저장하는 요청은 거부된다
- AC-3 [MUST] API: 관리자가 아닌 계정의 요청은 거부된다

## 정책 참조

- `_policy.md` 게임 목록
