# FR-ADM-001 신고 처리

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

관리자

## 선행조건

- 관리자로 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 관리자가 신고 목록에서 신고를 연다
2. 관리자가 대상 게시물·댓글을 확인하고 숨김 또는 기각을 고른다
3. 시스템이 처리 결과를 저장하고 신고자에게 알린다

## 예외 흐름

- E1. 대상이 이미 지워졌으면 → 신고를 종료 처리한다
