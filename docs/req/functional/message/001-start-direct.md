# FR-MSG-001 1:1 대화 시작

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 친구 목록이나 친구의 프로필에서 메시지를 누른다
2. 이미 대화방이 있으면 시스템이 그 방을 열고, 없으면 새로 만든다

## 예외 흐름

- E1. 상대가 친구가 아니면 → 메시지 버튼을 보여 주지 않는다
- E2. 상대가 나를 차단했으면 → 대화를 시작할 수 없다

## 수용 기준

- AC-1 [MUST] API: 친구에게 대화를 시작하면 두 회원 사이의 1:1 대화방이 하나만 생긴다. 이미 있으면 그 방을 돌려준다
- AC-2 [MUST] API: 친구가 아닌 회원이나 나를 차단한 회원과의 대화 시작은 거부된다
