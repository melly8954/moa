# FR-MSG-001 1:1 대화 시작

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 다른 회원의 프로필이나 친구 목록에서 메시지를 누른다
2. 이미 대화방이 있으면 시스템이 그 방을 열고, 없으면 새로 만든다

## 예외 흐름

- E1. 차단 관계면 → 대화를 시작할 수 없다
- E2. 자기 자신에게는 → 대화를 시작할 수 없다

## 수용 기준

- AC-1 [MUST] API: 다른 회원에게 대화를 시작하면 친구 여부와 상관없이 두 회원 사이의 1:1 대화방이 하나만 생긴다. 이미 있으면 그 방을 돌려준다
- AC-2 [MUST] API: 차단 관계인 회원과의 대화 시작은 거부된다
