# FR-MSG-006 1:1 대화방 나가기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (1:1 대화방 참여자)

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 1:1 대화방에서 나가기를 누르고 확인한다
2. 시스템이 내 목록에서 방을 지운다

## 예외 흐름

- E1. 확인에서 취소하면 → 나가지 않는다
- E2. 파티 채팅방이면 → 이 기능이 아니라 파티 나가기(FR-PTY-008)를 쓴다

## 수용 기준

- AC-1 [MUST] API: 나간 뒤 상대가 새 메시지를 보내면 방이 다시 나오고, 나가기 전 메시지는 내게 보이지 않는다
- AC-2 [MUST] API: 내가 나가도 상대의 대화 내용은 그대로다
