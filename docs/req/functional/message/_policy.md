# 메신저 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 대화방 종류 | 1:1 대화방과 파티 채팅방 두 가지. 그룹 대화방은 두지 않는다. 여럿이 이야기하려면 파티를 만든다 | 〔2026-09-25〕 사용자 결정. 그룹 대화방(FR-MSG-002, FR-MSG-005)을 지우고 파티로 합침 |
| 1:1 대화 조건 | 친구가 아니어도 누구에게나 1:1 메시지를 보낼 수 있다. 차단 관계면 시작하거나 보낼 수 없다 | 〔2026-09-25〕 인터뷰에서 비친구 메시지 불가로 정했으나 사용자가 인스타그램 DM처럼 누구나로 변경 |
| 파티 채팅방 | 파티마다 하나. 친구 여부와 상관없이 파티원만 읽고 쓴다. 새로 들어온 파티원도 이전 대화를 볼 수 있다 | 인터뷰 답, 파티 정책. 이전 대화 공개는 〔2026-09-25〕 사용자 결정 |
| 메시지 길이 | 최대 1,000자 | 〔2026-09-25〕 사용자 결정 |
| 메시지 첨부 | 텍스트, 이미지, 동영상. 첨부 형식·용량은 피드 정책의 첨부 규칙을 따른다 | 〔2026-09-25〕 텍스트 + 이미지를 추천했으나 사용자가 동영상까지 포함으로 결정 |
| 1:1 대화방 나가기 | 나가면 내 목록에서 사라지고 나가기 전 메시지는 내게 보이지 않는다. 상대가 새 메시지를 보내면 목록에 다시 나타난다 | 〔2026-09-25〕 사용자 결정 |
| 목록 정렬 | 대화 목록은 최근 메시지 순. 방마다 안 읽은 메시지 수를 보여 준다 | 인터뷰 답 |
