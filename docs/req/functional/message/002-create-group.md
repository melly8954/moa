# FR-MSG-002 그룹 대화방 만들기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 친구 목록에서 여러 명을 고른다
2. 회원이 방 이름을 정한다 (선택)
3. 시스템이 그룹 대화방을 만들고 고른 친구들을 넣는다

## 예외 흐름

- E1. 최대 인원을 넘기면 → 더 고를 수 없다
- E2. 고른 친구가 나를 차단했으면 → 그 친구는 넣지 않는다
