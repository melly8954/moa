# FR-MSG-004 대화 목록 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 메신저를 연다
2. 시스템이 1:1, 그룹, 파티 대화방을 최근 메시지 순으로 보여 주고 방마다 안 읽은 수를 표시한다
3. 회원이 방을 열면 그 방의 메시지를 읽음 처리한다

## 예외 흐름

- E1. 대화가 없으면 → 친구 목록으로 가는 안내를 보여 준다
