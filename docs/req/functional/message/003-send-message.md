# FR-MSG-003 메시지 보내기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (대화방 참여자)

## 선행조건

- 로그인한 상태다
- 1:1 대화방 참여자이거나 파티원이다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 대화방에서 텍스트를 쓰거나 이미지·동영상을 붙여 보낸다
2. 시스템이 참여자들에게 바로 전달하고 받는 사람의 안 읽은 수를 올린다

## 예외 흐름

- E1. 빈 메시지는 → 보내지 않는다
- E2. 길이·첨부 규칙에 맞지 않으면 → 보내지 않고 사유를 알린다
- E3. 전송에 실패하면 → 실패 표시와 다시 보내기를 보여 준다
- E4. 1:1 상대와 차단 관계가 됐으면 → 보내지 않는다

## 수용 기준

- AC-1 [MUST] API: 보낸 메시지가 다른 참여자에게 새로 고침 없이 전달된다
- AC-2 [MUST] API: 빈 메시지와 메시지 길이를 넘는 메시지는 거부된다
- AC-3 [MUST] API: 첨부 규칙에 맞지 않는 파일은 거부된다
- AC-4 [MUST] API: 파티원이 아닌 회원이 파티 채팅방에 보내면 거부된다
- AC-5 [MUST] API: 새로 들어온 파티원이 파티 채팅방을 열면 들어오기 전 메시지도 조회된다
- AC-6 [MUST] API: 1:1 상대와 차단 관계면 새 메시지가 거부된다
- AC-7 [MUST] 화면: 전송에 실패한 메시지에 실패 표시와 다시 보내기가 보인다
