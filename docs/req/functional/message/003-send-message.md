# FR-MSG-003 메시지 보내기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (대화방 참여자)

## 선행조건

- 로그인한 상태다
- 대화방 참여자다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 대화방에서 텍스트를 입력하거나 이미지·동영상을 붙여 보낸다
2. 시스템이 참여자들에게 바로 전달하고 안 읽은 수를 올린다

## 예외 흐름

- E1. 빈 메시지는 → 보내지 않는다
- E2. 첨부 형식이나 용량이 맞지 않으면 → 보내지 않고 사유를 알린다
- E3. 전송에 실패하면 → 실패 표시와 다시 보내기를 보여 준다
- E4. 1:1 상대가 그사이 나를 차단했으면 → 보내지 않는다
