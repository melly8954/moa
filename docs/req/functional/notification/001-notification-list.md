# FR-NTF-001 알림 목록 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 알림 배지를 누른다
2. 시스템이 알림을 최신순으로 보여 주고 읽음 처리한다
3. 회원이 알림을 누르면 관련 화면으로 간다

## 예외 흐름

- E1. 관련 대상이 지워졌으면 → 없는 대상이라고 알린다
- E2. 알림이 없으면 → 알림 없음 안내를 보여 준다
