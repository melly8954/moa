# 알림 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 알림 수단 | 서비스 안의 알림 목록과 배지만 쓴다. 웹 푸시와 활동 알림 이메일은 두지 않는다 | 인터뷰 답 (ck-fun-4) |
| 알림 사건 | 새 팔로우, 팔로우 요청, 팔로우 요청 승인, 좋아요, 댓글, 파티 참여 신청, 참여 신청 수락·거절, 파티 초대, 파티에서 내보내짐, 신고 처리 결과, 제재·해제, 로그인 수단 연결·추가·해제 | 인터뷰 답. 새 메시지는 알림 목록이 아니라 대화 목록의 안 읽은 수로 보여 준다 |
| 배지 | 안 읽은 알림 수 | 인터뷰 답 |
| 읽음 처리 | 알림 목록을 열면 목록의 알림을 모두 읽음으로 바꾼다 | 인터뷰 답 |
| 알림 보관 | 30일이 지난 알림은 지운다 | 〔2026-09-25〕 사용자 결정 |
