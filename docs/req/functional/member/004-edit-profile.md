# FR-MEM-004 프로필 편집

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 닉네임, 프로필 사진, 소개를 고친다
2. 회원이 플레이하는 게임을 고르고 게임마다 계정 이름과 티어를 입력한다
3. 시스템이 저장하고 프로필에 반영한다

## 예외 흐름

- E1. 닉네임 규칙에 맞지 않거나 이미 쓰이면 → 저장하지 않는다
- E2. 사진이 형식·용량 규칙에 맞지 않으면 → 저장하지 않고 사유를 알린다
- E3. 소개가 길이 규칙을 넘으면 → 저장하지 않는다
- E4. 저장하지 않고 나가면 → 고친 내용을 버린다

## 수용 기준

- AC-1 [MUST] API: 닉네임·소개·프로필 사진 규칙에 맞는 값과 게임 계정을 저장하면 프로필 조회 결과에 그대로 나온다
- AC-2 [MUST] API: 다른 회원이 쓰는 닉네임으로 바꾸면 거부된다
- AC-3 [MUST] API: 프로필 사진 규칙에 맞지 않는 사진(형식, 용량)은 거부된다
- AC-4 [MUST] API: 게임 목록에 없는 게임이나 티어 값은 거부된다
