# FR-MEM-004 프로필 편집

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 닉네임, 프로필 사진, 소개를 고친다
2. 회원이 플레이하는 게임(리그 오브 레전드, 오버워치, 배틀그라운드)을 고르고 게임별 계정 이름과 티어를 직접 입력한다
3. 시스템이 저장하고 프로필에 반영한다

## 예외 흐름

- E1. 바꾼 닉네임이 이미 쓰이고 있으면 → 저장하지 않고 다른 닉네임을 입력하게 한다
- E2. 사진 형식이나 용량이 맞지 않으면 → 저장하지 않고 사유를 알린다
- E3. 저장하지 않고 나가면 → 고친 내용을 버린다
