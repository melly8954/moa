# FR-MEM-008 회원 탈퇴

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 탈퇴를 요청하고 탈퇴 안내를 확인한다
2. 회원이 본인 확인을 한다
3. 시스템이 개인정보와 프로필을 지우고, 게시물·댓글·메시지는 탈퇴한 회원으로 익명화한다
4. 시스템이 로그아웃시킨다

## 예외 흐름

- E1. 본인 확인에 실패하면 → 탈퇴하지 않는다
- E2. 확인 단계에서 취소하면 → 탈퇴하지 않는다
