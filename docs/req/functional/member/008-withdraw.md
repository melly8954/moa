# FR-MEM-008 회원 탈퇴

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 탈퇴를 요청하고 탈퇴 안내(유예 기간, 복구 방법, 글 익명화)를 확인한다
2. 회원이 본인 확인을 한다
3. 시스템이 계정을 WITHDRAWN으로 바꾸고 로그아웃시킨다

## 예외 흐름

- E1. 본인 확인에 실패하면 → 탈퇴하지 않는다
- E2. 확인 단계에서 취소하면 → 탈퇴하지 않는다
- E3. 방장인 파티가 있으면 → 탈퇴 전에 방장을 넘기거나 파티를 나가라고 안내한다

## 수용 기준

- AC-1 [MUST] API: 본인 확인을 통과하면 계정이 WITHDRAWN이 되고 모든 세션이 끊긴다
- AC-2 [MUST] API: 탈퇴 직후 그 회원의 게시물·댓글·메시지 작성자가 탈퇴한 회원으로 응답된다
- AC-3 [MUST] API: 본인 확인에 실패하면 계정 상태가 바뀌지 않는다
- AC-4 [MUST] API: 방장인 파티가 남아 있으면 탈퇴가 거부된다
- AC-5 [MUST] 화면: 탈퇴 안내에 유예 기간과 관리자 문의로만 복구된다는 내용이 보인다
