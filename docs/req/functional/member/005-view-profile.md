# FR-MEM-005 프로필 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 회원의 프로필을 연다
2. 시스템이 닉네임, 사진, 소개, 플레이하는 게임과 티어, 팔로워·팔로잉 수, 게시물 목록을 보여 준다

## 예외 흐름

- E1. 비공개 계정이고 승인된 팔로워가 아니면 → 게시물 목록 대신 비공개 안내와 팔로우 요청 버튼을 보여 준다
- E2. 나를 차단한 회원의 프로필이면 → 찾을 수 없는 회원으로 보여 준다
- E3. 탈퇴하거나 정지된 회원이면 → 찾을 수 없는 회원으로 보여 준다
