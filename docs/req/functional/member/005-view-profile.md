# FR-MEM-005 프로필 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 회원의 프로필을 연다
2. 시스템이 닉네임, 사진, 소개, 플레이하는 게임과 티어, 레벨·평판 요약, 팔로워·팔로잉 수, 게시물 목록을 보여 준다

## 예외 흐름

- E1. 비공개 계정이고 승인된 팔로워가 아니면 → 게시물 목록 대신 비공개 안내와 팔로우 버튼을 보여 준다
- E2. 찾을 수 없는 회원이면 → 찾을 수 없는 회원이라고 보여 준다

## 수용 기준

- AC-1 [MUST] API: 비공개 계정 프로필을 승인된 팔로워가 아닌 사용자가 조회하면 게시물 목록이 응답에 없다. 관리자는 예외로 게시물 목록을 받는다 〔2026-10-02〕 사용자 결정
- AC-2 [MUST] API: 나를 차단한 회원, WITHDRAWN·SUSPENDED 회원의 프로필은 찾을 수 없음으로 응답한다. 관리자는 예외로 상태와 함께 프로필을 받는다 〔2026-10-02〕 사용자 결정
- AC-3 [MUST] API: 다른 회원의 프로필 응답에 이메일, 생년월일, 휴대폰 번호가 없다

- `_policy.md` 찾을 수 없는 회원
