# FR-MEM-006 회원 검색

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 닉네임을 입력한다
2. 시스템이 닉네임이 일치하거나 포함된 회원 목록을 보여 준다
3. 사용자가 회원을 고르면 프로필로 간다

## 예외 흐름

- E1. 결과가 없으면 → 결과 없음 안내를 보여 준다
- E2. 나를 차단한 회원은 → 결과에서 뺀다
