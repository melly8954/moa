# FR-MEM-006 회원 검색

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 닉네임을 입력한다
2. 시스템이 닉네임에 입력어가 포함된 회원을 보여 준다
3. 사용자가 회원을 고르면 프로필로 간다

## 예외 흐름

- E1. 결과가 없으면 → 결과 없음 안내를 보여 준다

## 수용 기준

- AC-1 [MUST] API: 입력어를 포함한 닉네임의 회원이 대소문자 구분 없이 결과에 나온다
- AC-2 [MUST] API: 찾을 수 없는 회원은 결과에 나오지 않는다

## 정책 참조

- `_policy.md` 찾을 수 없는 회원
