# FR-MEM-007 계정 공개 범위 설정

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 계정을 공개 또는 비공개로 바꾼다
2. 시스템이 저장한다. 비공개면 이후 새 팔로우는 승인이 필요하다

## 예외 흐름

- E1. 비공개에서 공개로 바꿀 때 대기 중인 팔로우 요청이 있으면 → 공개 전환 시 대기 요청 규칙대로 처리한다

## 수용 기준

- AC-1 [MUST] API: 비공개로 바꾼 뒤의 팔로우는 요청 상태로 저장된다
- AC-2 [MUST] API: 비공개에서 공개로 바꾸면 대기 중인 팔로우 요청이 모두 없어지고 팔로우도 맺어지지 않는다
- AC-3 [MUST] API: 비공개로 바꿔도 이미 맺은 팔로우는 유지된다

## 정책 참조

- `_policy.md` 계정 공개 범위
- `_policy.md` 공개 전환 시 대기 요청
