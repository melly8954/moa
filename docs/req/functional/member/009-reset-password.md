# FR-MEM-009 비밀번호 재설정

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원

## 선행조건

- 로그인하지 않은 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 비회원이 로그인 화면에서 비밀번호 찾기를 누르고 이메일을 입력한다
2. 시스템이 재설정 링크를 메일로 보낸다
3. 비회원이 링크를 열어 새 비밀번호를 정한다
4. 시스템이 비밀번호를 바꾸고 기존 세션을 모두 끊은 뒤 로그인 화면으로 보낸다

## 예외 흐름

- E1. 가입하지 않은 이메일이어도 → 같은 안내를 보여 준다 (가입 여부를 드러내지 않는다)
- E2. 링크가 만료됐거나 이미 쓰였으면 → 다시 요청하게 한다
- E3. 비밀번호가 없는 계정이면 → 메일에 연결된 구글·카카오로 로그인하거나, 로그인 뒤 로그인 수단 관리(FR-MEM-011)에서 비밀번호를 추가하라고 안내한다

## 수용 기준

- AC-1 [MUST] API: 가입한 이메일과 가입하지 않은 이메일의 재설정 요청 응답이 같다
- AC-2 [MUST] API: 유효한 링크로 정책에 맞는 새 비밀번호를 정하면 새 비밀번호로 로그인되고 옛 비밀번호로는 안 된다
- AC-3 [MUST] API: 한 번 쓴 링크와 만료된 링크는 거부된다
