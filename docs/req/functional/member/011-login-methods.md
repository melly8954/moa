# FR-MEM-011 로그인 수단 관리

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 설정에서 로그인 수단 관리를 연다
2. 시스템이 계정 이메일과 연결된 수단(비밀번호, 구글, 카카오)을 보여 준다
3. 회원이 구글·카카오를 연결하려면 해당 서비스에서 인증한다. 시스템이 계정에 연결한다
4. 회원이 비밀번호를 추가하거나 수단을 해제하려면 본인 확인을 한 뒤 진행한다
5. 시스템이 저장하고 서비스 안 알림을 남긴다

## 예외 흐름

- E1. 연결하려는 구글·카카오 계정이 이미 다른 moa 계정에 연결돼 있으면 → 연결하지 않는다
- E2. 남은 수단이 하나뿐이면 → 해제할 수 없다
- E3. 본인 확인에 실패하면 → 바꾸지 않는다
- E4. 추가하려는 비밀번호가 비밀번호 정책에 맞지 않으면 → 추가하지 않는다
- E5. 구글·카카오 인증을 취소하면 → 연결하지 않는다

## 수용 기준

- AC-1 [MUST] API: 구글·카카오를 연결하면 그 수단으로 로그인했을 때 같은 계정으로 들어온다
- AC-2 [MUST] API: 이미 다른 계정에 연결된 구글·카카오 계정의 연결은 거부된다
- AC-3 [MUST] API: 비밀번호를 추가하면 계정 이메일과 그 비밀번호로 로그인된다
- AC-4 [MUST] API: 수단이 하나만 남은 계정의 해제는 거부된다
- AC-5 [MUST] API: 본인 확인 없이 한 비밀번호 추가·해제 요청은 거부된다
- AC-6 [MUST] API: 연결·추가·해제 때 알림 목록에 알림이 생기고 메일은 나가지 않는다
