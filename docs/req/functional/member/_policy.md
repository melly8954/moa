# 회원 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치, 상태 전이다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 로그인 수단 | 이메일+비밀번호, 구글, 카카오. 계정 하나에 세 수단을 모두 연결할 수 있다(통합 계정) | 인터뷰 답 (ck-sec-1). 통합 계정은 〔2026-09-25〕 사용자 결정 |
| 계정 이메일 | 모든 계정에 이메일이 하나 있다. 이메일 가입은 입력한 이메일, 구글·카카오 가입은 제공자가 준 이메일, 카카오가 이메일을 주지 않으면 이메일 가입 단계에서 인증한 이메일이다. 비밀번호 로그인은 계정 이메일로 한다 | 〔2026-09-25〕 사용자 결정 |
| 이메일 인증 연결 | 이메일 인증으로 주인임이 확인된 이메일이 기존 계정의 이메일과 같으면, 새 계정을 만들지 않고 그 계정에 연결한다. 기존 계정에 비밀번호가 없으면 비밀번호를 추가하고, 카카오 가입 중이었으면 카카오도 연결한다. 기존 계정에 비밀번호가 이미 있으면 이메일 가입을 막고 로그인·비밀번호 찾기로 안내한다 | 〔2026-09-25〕 사용자 결정 |
| 카카오 이메일 없음 | 카카오가 이메일을 주지 않으면 이메일 가입 단계(이메일, 비밀번호, 이메일 인증)로 이어 간다. 인증한 이메일에 이메일 인증 연결 규칙을 적용한다 | 〔2026-09-25〕 사용자 결정 |
| 가입 수집 항목 | 이메일, 생년월일, 휴대폰 번호. 가입 수단과 상관없이 모두 받는다 | 인터뷰 답 (ck-sec-2) |
| 가입 나이 | 만 14세 이상 | 〔2026-09-25〕 인터뷰에서 사용자 결정 |
| 1인 1계정 | 인증된 휴대폰 번호 하나에 계정 하나 | 〔2026-09-25〕 인터뷰에서 사용자 결정 |
| 휴대폰 번호 중복 안내 | 가입 중 휴대폰 번호가 기존 계정과 겹치면 가입을 막고, 기존 계정 이메일을 일부 가려 보여 주며(예: ab***@naver.com) 그 계정으로 로그인한 뒤 로그인 수단 관리에서 연결하라고 안내한다 | 〔2026-09-25〕 사용자 결정 |
| 로그인 수단 관리 | 구글·카카오 연결은 해당 서비스 인증으로 한다. 한 구글·카카오 계정은 moa 계정 하나에만 연결된다. 비밀번호 추가와 수단 해제는 가진 수단 중 하나로 본인 확인(비밀번호 또는 소셜 재인증)을 한 뒤 한다. 수단이 하나만 남으면 해제할 수 없다 | 〔2026-09-25〕 사용자 결정 |
| 로그인 수단 변경 알림 | 수단이 연결·추가·해제되면 서비스 안 알림으로만 알린다. 메일은 보내지 않는다 | 〔2026-09-25〕 알림 메일을 추천했으나 사용자가 보내지 않음으로 결정 |
| 계정 합치기 | 구글·카카오 계정의 이메일이 기존 계정 이메일과 같고, 제공자가 인증된 이메일로 알려 주면 로그인 순간 기존 계정에 합친다 | 〔2026-09-25〕 막고 원래 수단 안내를 추천했으나 사용자가 자동으로 합침으로 결정 |
| 닉네임 | 2~12자, 한글·영문·숫자·밑줄(_). 대소문자를 구분하지 않고 중복 불가 | 〔2026-09-25〕 사용자 결정 |
| 소개 | 최대 150자 | 〔2026-09-25〕 사용자 결정 |
| 프로필 사진 | JPG·PNG·WEBP, 최대 5MB | 〔2026-09-25〕 사용자 결정 |
| 게임 계정·티어 | 회원이 직접 입력하고 검증하지 않는다. 게임·티어 선택지는 관리자 게임 목록(FR-ADM-004)을 따른다 | 인터뷰 답. 게임사 API 연동은 범위 밖 |
| 계정 공개 범위 | 공개 또는 비공개. 비공개 계정의 게시물·팔로워·팔로잉 목록은 승인된 팔로워만 본다 | 인터뷰 답 (ck-act-2) |
| 공개 전환 시 대기 요청 | 비공개에서 공개로 바꾸면 대기 중인 팔로우 요청을 모두 지운다 | 〔2026-09-25〕 모두 자동 승인을 추천했으나 사용자가 모두 삭제로 결정 |
| 찾을 수 없는 회원 | WITHDRAWN·SUSPENDED 회원과 나를 차단한 회원은 프로필·검색·목록에서 찾을 수 없는 회원으로 다룬다 | 인터뷰 답 (ck-act-2) |
| 탈퇴 본인 확인 | 비밀번호가 있으면 비밀번호, 없으면 연결된 구글·카카오 재인증 | 〔2026-09-25〕 사용자 결정 |
| 탈퇴 유예 | 탈퇴 후 30일. 이 기간에는 회원이 전화·개인 문의로 요청하면 관리자가 복구한다(FR-ADM-005). 회원이 스스로 철회하는 기능은 없다 | 〔2026-09-25〕 로그인 시 철회를 추천했으나 사용자가 관리자 복구로 결정 |

## 상태 전이: 회원 계정

<!-- 상태값의 정본은 이 절이다. 코드의 상태 이름은 이 절을 따른다 -->

### 상태

| 상태 | 의미 |
|---|---|
| ACTIVE | 정상 |
| SUSPENDED | 관리자 제재로 정지. 로그인할 수 없다 |
| WITHDRAWN | 탈퇴 후 유예 중. 로그인할 수 없고 찾을 수 없는 회원으로 보인다 |
| PURGED | 개인정보를 파기했다. 되돌릴 수 없다 |
