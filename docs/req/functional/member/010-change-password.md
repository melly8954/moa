# FR-MEM-010 비밀번호 변경

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다
- 이메일로 가입한 회원이다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 현재 비밀번호와 새 비밀번호를 입력한다
2. 시스템이 비밀번호를 바꾸고 지금 세션을 뺀 다른 세션을 끊는다

## 예외 흐름

- E1. 현재 비밀번호가 틀리면 → 바꾸지 않는다
- E2. 새 비밀번호가 비밀번호 정책에 맞지 않으면 → 바꾸지 않고 사유를 알린다

## 수용 기준

- AC-1 [MUST] API: 현재 비밀번호가 맞고 새 비밀번호가 정책에 맞으면 바뀌고, 다른 기기의 세션이 끊긴다
- AC-2 [MUST] API: 현재 비밀번호가 틀리면 거부된다
