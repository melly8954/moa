# FR-MEM-001 회원가입

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 비회원이 가입 화면에서 가입 수단을 고른다 <!-- 인증 방식은 ck-sec-1에서 정한다 -->
2. 비회원이 닉네임과 필수 약관 동의를 입력한다
3. 시스템이 회원을 만들고 로그인 상태로 홈으로 보낸다

## 예외 흐름

- E1. 닉네임이 이미 쓰이고 있으면 → 다른 닉네임을 입력하게 한다
- E2. 필수 약관에 동의하지 않으면 → 가입을 진행하지 않는다
- E3. 가입 중에 취소하면 → 아무것도 저장하지 않는다
