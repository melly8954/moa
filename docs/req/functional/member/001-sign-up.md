# FR-MEM-001 회원가입

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 비회원이 가입 수단(이메일, 구글, 카카오)을 고른다
2. 이메일이면 이메일과 비밀번호를 입력하고, 시스템이 보낸 인증 메일로 이메일을 인증한다
3. 구글·카카오면 해당 서비스에서 인증하고 돌아온다
4. 비회원이 생년월일을 입력하고, 휴대폰 번호를 문자 인증한다
5. 비회원이 닉네임과 필수 약관 동의를 입력한다
6. 시스템이 회원을 만들고 로그인 상태로 홈으로 보낸다

## 예외 흐름

- E1. 이미 가입된 이메일이면 → 이메일 가입이면 가입을 막고 로그인하라고 안내한다. 구글·카카오면 같은 이메일의 기존 계정에 자동으로 합치고 로그인시킨다 〔2026-09-25〕 막고 원래 수단 안내를 추천했으나 사용자가 자동으로 합침으로 결정. 구글·카카오가 인증된 이메일로 알려 줄 때만 합친다
- E2. 이메일 인증을 기한 안에 하지 않으면 → 가입을 끝내지 않는다. 인증 메일을 다시 보낼 수 있다
- E3. 구글·카카오 인증에 실패하거나 취소하면 → 가입 화면으로 돌아간다
- E4. 만 14세 미만이면 → 가입을 막는다
- E5. 이미 다른 계정에 인증된 휴대폰 번호면 → 가입을 막고 기존 계정으로 로그인하라고 안내한다
- E6. 문자 인증에 실패하거나 기한이 지나면 → 인증 문자를 다시 받게 한다
- E7. 닉네임이 이미 쓰이고 있으면 → 다른 닉네임을 입력하게 한다
- E8. 필수 약관에 동의하지 않으면 → 가입을 진행하지 않는다
- E9. 가입 중에 취소하면 → 아무것도 저장하지 않는다
