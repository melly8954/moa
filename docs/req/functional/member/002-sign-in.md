# FR-MEM-002 로그인

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 비회원이 이메일·비밀번호를 입력하거나 구글·카카오로 인증한다
2. 시스템이 로그인 상태로 만들고 직전에 보던 화면이나 홈으로 보낸다

## 예외 흐름

- E1. 인증에 실패하면 → 실패 사유를 알리고 다시 시도하게 한다
- E2. 가입하지 않은 구글·카카오 계정이면 → 회원가입(FR-MEM-001)으로 이어간다
- E3. 제재로 정지된 회원이면 → 로그인을 막고 정지 사유와 기간을 보여 준다
