# FR-MEM-002 로그인

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원

## 선행조건

- 로그인하지 않은 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 비회원이 이메일·비밀번호를 입력하거나 구글·카카오로 인증한다
2. 시스템이 로그인 세션을 발급하고 직전에 보던 화면이나 홈으로 보낸다 (관리자는 관리자 콘솔의 신고 목록으로 보낸다 〔2026-10-02〕 사용자 결정. 관리자는 회원 화면을 메뉴로 다니지 않고, 신고·회원 상세의 원문 보기로만 연다)

## 예외 흐름

- E1. 이메일이나 비밀번호가 틀리면 → 어느 쪽이 틀렸는지 밝히지 않고 실패를 알린다
- E2. 가입하지 않은 구글·카카오 계정이면 → 회원가입(FR-MEM-001)으로 이어간다
- E3. SUSPENDED 회원이면 → 로그인을 막고 정지 사유와 끝나는 날을 보여 준다
- E4. WITHDRAWN 회원이면 → 로그인을 막고 탈퇴한 계정이라고 안내한다

## 수용 기준

- AC-1 [MUST] API: 올바른 이메일·비밀번호로 로그인하면 세션이 발급된다
- AC-2 [MUST] API: 틀린 비밀번호와 없는 이메일에 같은 실패 응답을 준다
- AC-3 [MUST] API: SUSPENDED·WITHDRAWN 회원의 로그인은 거부되고 세션이 발급되지 않는다
- AC-4 [MUST] 화면: 정지된 회원이 로그인하면 정지 사유와 끝나는 날이 보인다
