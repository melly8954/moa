# FR-MAT-002 AI 친구 추천

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 추천 친구 목록을 연다
2. 시스템이 게임·티어·플레이 성향·평판이 맞는 회원을 추천 이유와 함께 보여 준다
3. 회원이 팔로우하거나 추천을 넘긴다

## 예외 흐름

- E1. 추천할 회원이 없으면 → 플레이 성향 설정과 게임별 피드로 가는 안내를 보여 준다
- E2. 넘긴 회원은 → 다시 추천하지 않는다
