# FR-MAT-001 플레이 성향 설정

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원

## 선행조건

- 로그인한 상태다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 게임별 플레이 목적, 보이스 사용 여부, 주 플레이 시간대를 고른다
2. 시스템이 저장하고 추천에 쓴다

## 예외 흐름

- E1. 설정하지 않으면 → 게임·티어·평판만으로 추천한다

## 수용 기준

- AC-1 [MUST] API: 저장한 플레이 성향이 조회 결과에 그대로 나온다
