# 매칭 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 구현 시기 | MVP 이후 | 인터뷰 답 |
| 추천 근거 | 플레이하는 게임, 티어, 플레이 성향, 평판, 반응 이력 | 인터뷰 답 |
| 추천 방식 | AI 모델이나 외부 AI API 사용 여부는 설계에서 정한다 | 인터뷰 답 |
| 추천 제외 | 찾을 수 없는 회원, 차단 관계인 회원, 이미 친구인 회원(친구 추천), 이미 파티원인 파티(파티 추천), 넘긴 추천 | 인터뷰 답 |
| 플레이 성향 | 게임별 플레이 목적(즐겜·빡겜), 보이스 사용 여부, 주 플레이 시간대 | 인터뷰 답. 선택지 목록은 설계에서 확정한다 |
