# 평판 정책

둘 이상의 기능이 함께 쓰는 규칙과 수치다. 값의 정의는 이 파일에만 둔다.

## 규칙·수치

| 항목 | 값 | 근거 |
|---|---|---|
| 평가 시점 | 파티를 나갈 때만 평가한다. 나간 뒤 7일 안에는 평가할 파티원 목록에서 이어서 할 수 있다 | 〔2026-09-25〕 사용자 결정. 같이 플레이했는지 확인할 방법이 없어 모집 성사 기준 평가는 두지 않는다. 나간 뒤 7일은 사용자 결정 |
| 평가 대상 | 나갈 때 남아 있던 파티원 중 평가 시점에 친구(맞팔)가 아니고 차단 관계가 아닌 회원 | 〔2026-09-25〕 사용자 결정 (친구 제외) |
| 평가 횟수 | 한 번 나갈 때 대상 한 명에게 한 번 | 〔2026-09-25〕 사용자 결정 |
| 평가 방식 | 추천 또는 비추천 중 하나와 태그. 추천 태그: 매너 좋음, 실력 좋음, 소통 잘함. 비추천 태그: 비매너, 욕설, 탈주, 노쇼. 누가 평가했는지는 공개하지 않는다 | 〔2026-09-25〕 사용자 결정 |
| 평판 표시 | 추천 비율(추천 ÷ 받은 평가 수)과 많이 받은 태그 3개. 받은 평가가 없으면 평가 없음 | 〔2026-09-25〕 사용자 결정 |
| 경험치 | 게시물 작성 10, 댓글 작성 2, 모집 성사 때 파티원 20, 받은 추천 30, 받은 비추천 -30 | 〔2026-09-25〕 평판만 쓰는 안을 추천했으나 사용자가 활동 포함으로 결정 |
| 활동 경험치 한도 | 게시물·댓글·모집 성사 경험치는 하루 합계 100까지. 평가 경험치는 한도가 없다 | 〔2026-09-25〕 사용자 결정 |
| 레벨 | 1~50. 레벨 n에서 n+1이 되려면 경험치 n × 100이 더 필요하다. 경험치가 줄면 레벨도 내려간다. 경험치는 0 아래로 내려가지 않는다 | 〔2026-09-25〕 사용자 결정 |
