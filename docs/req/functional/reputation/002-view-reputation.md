# FR-REP-002 평판·레벨 보기

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

비회원, 회원

## 선행조건

- 없음

## 주 흐름

<!-- ck-fun-3 -->

1. 사용자가 회원의 프로필을 연다
2. 시스템이 레벨과 평판 표시를 보여 준다

## 예외 흐름

- E1. 받은 평가가 없으면 → 평가 없음으로 보여 준다

## 수용 기준

- AC-1 [MUST] API: 평판 표시(추천 비율, 많이 받은 태그)가 받은 평가대로 계산된다
- AC-2 [MUST] API: 경험치에 맞는 레벨이 나오고, 경험치가 줄면 레벨이 내려간다
- AC-3 [MUST] API: 활동 경험치는 하루에 활동 경험치 한도를 넘게 쌓이지 않는다

## 정책 참조

- `_policy.md` 평판 표시
- `_policy.md` 경험치
- `_policy.md` 활동 경험치 한도
- `_policy.md` 레벨
