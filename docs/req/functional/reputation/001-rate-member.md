# FR-REP-001 파티원 평가

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (파티를 나간 회원)

## 선행조건

- 로그인한 상태다
- 평가 시점 안의 나간 파티가 있다

## 주 흐름

<!-- ck-fun-3 -->

1. 파티를 나가면 시스템이 평가 대상 목록을 보여 준다
2. 회원이 대상마다 추천 또는 비추천과 태그를 고르거나 건너뛴다
3. 시스템이 평가를 저장하고 상대의 평판과 경험치에 반영한다

## 예외 흐름

- E1. 평가 대상이 없으면 → 평가 화면을 건너뛴다
- E2. 이미 평가한 대상이면 → 다시 평가할 수 없다
- E3. 평가 시점이 지났으면 → 평가할 수 없다

## 수용 기준

- AC-1 [MUST] API: 나간 파티에서 대상에게 평가하면 대상의 평판과 경험치가 바뀐다
- AC-2 [MUST] API: 친구, 차단 관계인 회원, 나 자신에 대한 평가는 거부된다
- AC-3 [MUST] API: 같은 퇴장에서 같은 대상을 두 번 평가하면 거부된다
- AC-4 [MUST] API: 평가 시점이 지난 파티의 평가는 거부된다
- AC-5 [MUST] API: 평가 조회 응답 어디에도 평가한 사람이 드러나지 않는다
