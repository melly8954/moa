# FR-REP-001 파티원 평가

<!-- refs: 이 기능에만 적용되는 NFR·SEC·INT·DAT ID. 전체 적용 항목은 적지 않는다 -->

## 행위자

회원 (파티원)

## 선행조건

- 로그인한 상태다
- 평가가 열린 파티의 파티원이었다

## 주 흐름

<!-- ck-fun-3 -->

1. 회원이 평가할 파티 목록에서 파티를 고른다
2. 회원이 다른 파티원마다 평가를 남긴다
3. 시스템이 평가를 반영해 상대의 평판을 갱신한다

## 예외 흐름

- E1. 이미 평가한 파티원이면 → 다시 평가할 수 없다
- E2. 평가 기한이 지났으면 → 평가할 수 없다
- E3. 자기 자신은 → 평가할 수 없다
