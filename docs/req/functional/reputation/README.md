## 정책 후보

<!-- 인터뷰에서 나온 규칙·수치 후보다. psw-req가 _policy.md로 옮기고 이 절을 지운다 -->

- 평가는 같은 파티가 성사된 뒤 일정 시간이 지나면 파티원끼리만 할 수 있다 〔2026-09-25〕 방장의 플레이 완료를 추천했으나 사용자가 성사 후 일정 시간으로 결정
- 레벨은 활동 점수와 평판 점수를 합쳐 오른다 〔2026-09-25〕 평판만 쓰는 안을 추천했으나 사용자가 활동 포함으로 결정. 활동 항목과 점수 계산은 psw-req에서 정한다
- 평가 항목·척도, 한 파티원에게 한 번만 평가하는지, 평가 기한은 psw-req에서 정한다
